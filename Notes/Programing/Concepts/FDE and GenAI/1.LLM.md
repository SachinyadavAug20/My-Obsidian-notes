##### Why tokenizer will choose set of char instead of words ?
- can we simply do each word will be a token.
- problem vocabulary of a language is very vast can't give unique token to each word. => Automatically,Automate,Automation -> are similar so make it reusable token like `Auto` will be a token.
- ![[Pasted image 20260926091752.png]]
- thus, tokenizer is optimized to minimize number of tokens and make reusable general purpose tokens.
- As modern model will try to increase vocabulary so make no of token less.
