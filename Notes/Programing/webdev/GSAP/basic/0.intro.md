### Methods in `gsap`
- `to(element identifier,{css})` -> from initial position to this `css` 
- `from(element identifier,{css})` -> final to initial (from this `css` to current css)
example :
```js
gsap.to("#box1",{
  x:500,
  duration:2, 
  delay:1
}) // element(same name as in css),{css properties}
gsap.from("#box2",{
  x:500,
  duration:2, 
  delay:1
})
```
Like we place element in correct place by css then, we want it to animate to some css and come back to initial css. So, use `.from`
```js
gsap.from("h1",{
  opacity:0,
  duration:2,
  y:20,
  delay:1,
  stagger:1,
})
```
stagger is a all '`h1`' comes one by one 
```js
gsap.to("#box3",{
  x:800,
  duration:2, 
  delay:1,
  rotate:90,
  repeat:-1, // repeat 1 time means run once and one repeat = 2 time
  yoyo:true, // initial to final and final to initial so on
})
```
## Timeline
need to take care of time-taken to complete animation.
for example animate 3 boxes one after another
```java
gsap.to("#box4",{
  x:1500,
  rotate:360,
  duration:1.5,
  borderRadius:"30%",
  delay:1,
}) // time taken = 1+1.5=2.5
gsap.to("#box5",{
  x:1500,
  rotate:360,
  duration:1.5,
  borderRadius:"25%",
  delay:3, // for previous animation time + 0.5
})
gsap.to("#box6",{
  x:1500,
  rotate:360,
  duration:1.5,
  borderRadius:"20%",
  delay:5, // for previous animation time(3+0.5) + 0.5
})
```
for many element can lead to problem (need to do alot of calculation)
solved by using timeline
time of each element is different --> async 
==> make animation sync
```js
var tl = gsap.timeline();
tl.to("#box4",{
  x:1500,
  rotate:360,
  duration:0.5,
  borderRadius:"30%",
  delay:1,
})
tl.to("#box5",{
  x:1500,
  rotate:360,
  duration:1.5,
  borderRadius:"25%",
  delay:0.5, 
})
tl.to("#box6",{
  x:1500,
  rotate:360,
  duration:1.5,
  borderRadius:"20%",
  delay:0.5,
})
```
