It brings ACID(Atomicity consistency isolation durability) property to SQL DB.
#### Atomicity
smallest unit of operation which can't be divided further.
it is completed full or none.
#### Consistency
Any transaction on DB will take the DB from 1 valid state to other valid state.(like -ve balance not allowed, conservation of money in transaction).
#### Isolation
concurrent transaction -> many transaction run on same table row.![[Pasted image 20260826101459.png]]
T1 and T2 -> will run in isolation that is one at a time to avoid race condition.
T1 and T2 -> will run isolatedly can't see in middel of working of each other will only see final state of produced by the other transcation.
#### Durable
one transaction sucessfull it should be able to rersist the data.
committed operation should be as it is not effected by future failures.
ACID and transactions are properties of SQL DB.
at spring boot we will use it -> 
- physical transaction: it is done at DB level.
- virtual transaction: it is done at spring app level.

    public void debitAccount(BigDecimal amount) {
        if(amount==null || amount.signum()<=0) {
            throw new IllegalArgumentException("Amount should be a positive number");
        }
        if(balance.compareTo(amount)<0) {
            throw new RuntimeException("Not enough balance to debit");
        }
        balance = balance.subtract(amount);
    }
    public void creditAccount(BigDecimal amount) {
        if(amount==null || amount.signum()<=0) {
            throw new IllegalArgumentException("Amount should be a positive number");
        }
        balance = balance.add(amount);
    }

```java
    @Transactional
    public void transfer(Long fromAccountId, Long toAccountId, BigDecimal amount) throws RuntimeException {
        Account fromAccount = accountRepository.findById(fromAccountId)
            .orElseThrow(() -> new RuntimeException("From Account not found"));
        Account toAccount = accountRepository.findById(toAccountId)
            .orElseThrow(() -> new RuntimeException("To Account not found"));
        fromAccount.debitAccount(amount);
        accountRepository.flush();
        toAccount.creditAccount(amount);
        accountRepository.flush();
        TransferRecord transferRecord = new TransferRecord(fromAccountId, toAccountId, amount, LocalDate.now());
        transferRecordRepository.save(transferRecord);
        transferRecordRepository.flush();

        throw new RuntimeException("Something went wrong"); // will rollback all flush
    }
```
