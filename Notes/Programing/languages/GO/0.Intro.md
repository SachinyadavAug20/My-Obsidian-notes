## Compilation
`.go` file contain human readable code.
computer understands binary.
convert human readable code to binary is compilation.
```bash
go build
```
it will build `helloworld.exe` for the file which has package main.
2 types of error 
- compile time(good safe code)
- runtime error(bad crash)
