## Prototype design problem
if have object created by a class.
![[Pasted image 20261124111451.png]]
will get object in heap.
to create more and more object need to do same thing repeatedly.
![[Pasted image 20261124113054.png]]
problem
1. Creation of object is expensive operation.
2. if need to create many objects for it.
example: `NPC`(non-player-character) loading on game.
generating `NPC` is expensive => need to create 100 of such object.
solved using prototype design pattern => create copy of original object instead of creating new.
that is cloning the object is cheap operation.

### With prototype 
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// Cloneable (aka Prototype) interface
class Cloneable {
public:
    virtual Cloneable* clone() const = 0;
    virtual ~Cloneable() {}
};

class NPC : public Cloneable {
public:
    string name;
    int health;
    int attack;
    int defense;

    NPC(const string& name, int health, int attack, int defense) {
        // call database
        // complex calc
        this->name = name; 
        this->health = health; 
        this->attack = attack; 
        this->defense = defense;
        cout << "Setting up template NPC '" << name << "'\n";
    }

    // copy‐ctor used by clone()
    NPC(const NPC& other) {
        name = other.name;
        health = other.health;
        attack = other.attack;
        defense = other.defense;
        cout << "Cloning NPC '" << name << "'\n";
    }

    // the clone method required by Prototype
    Cloneable* clone() const override {
        return new NPC(*this);
    }

    void describe() {
        cout << "NPC " << name  << " [HP=" << health  << " ATK=" << attack 
             << " DEF=" << defense << "]\n";
    }

    // setters to tweak the clone…
    void setName(const string& n) { 
        name = n;
    }
    void setHealth(int h) { 
        health = h;
    }
    void setAttack(int a) {
         attack = a; 
    }
    void setDefense(int d){ 
        defense = d;
    }
};

int main() {
    // 1) build one “heavy” template
    NPC* alien = new NPC("Alien", 30, 5, 2);

    // 2) quickly clone + tweak as many variants as you like:
    NPC* alienCopied1 = dynamic_cast<NPC*>(alien->clone());
    alienCopied1->describe();

    NPC* alienCopied2 = dynamic_cast<NPC*>(alien->clone());
    alienCopied2->setName("Powerful Alien");
    alienCopied2->setHealth(50);
    alienCopied2->describe();

    // cleanup
    delete alien;
    delete alienCopied1;
    delete alienCopied2;
}
```
## Shallow and deep copy
2 type of copy 
1. Shallow copy 
   copy reference (here used only primitive int thus, here we get value copied thus, deep copy(as stored in stack) by default)
   for non-primitive data-type => will have shallow copy both reference point to same location in heap memory
   ![[Pasted image 20261126114701.png]]
2. Deep copy
   actually different object made identical to other
for deep copy => use `new` keyword with same value using copy constructor.
