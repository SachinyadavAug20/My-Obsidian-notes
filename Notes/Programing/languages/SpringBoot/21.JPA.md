is it null able or not ? ![[Pasted image 20260817210238.png]] is possible it is nullable relationship(by default).
can make it non-nullable also:
```java
	@ManyToOne(optional=false)
    @JoinColumn(name = "department_id",nullable=false)
    private Department department;
```
optional = false -> tell java each student must have a department.
nullable = false -> tell SQL the colume will not be null.

```java
@RestController
@RequestMapping("/api/department")
public class DepartmentController {
    DepartmentService departmentService;
    public DepartmentController(DepartmentService departmentService) {
        this.departmentService = departmentService;
    }

    @PostMapping
    public ResponseEntity<Department> save(@RequestBody Department department) {
        return ResponseEntity.ok().body(departmentService.save(department));
    }
}

@Service
public class DepartmentService {
    private DepartmentRepository departmentRepository;
    public DepartmentService(DepartmentRepository departmentRepository) {
        this.departmentRepository = departmentRepository;
    }
    
    @Transactional
    public Department save(Department department) {
        return departmentRepository.save(department);
    }

}

@Repository
public class DepartmentRepository {
    @PersistenceContext
    private EntityManager entityManager;
    public Department save(Department department) {
        entityManager.persist(department);
        return department;
    }
    public Department get(Long id) {
        return entityManager.find(Department.class, id);
    }
}
```
