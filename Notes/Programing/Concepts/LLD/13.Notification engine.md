## `NotificationService`
this will attach notification to observable, send notification.
and observers will do work on it.
![[Pasted image 20261002161237.png]]
Now, need to store the notification using notification service.
before sending to observable will store in a vector.
over all 3 parts
- make notification -> using `INotification`(and it's implementation), also decorators on it more adding more features on notification.(Decorator design pattern)
- send notification -> via observers and strategies for it(Observer and strategy design pattern)
- service -> connect above 2 parts and also store the record => this will be singleton class(Singleton design pattern)
used 4 design pattern connected to make a complete notification service.
it follows all the functional and non-functional requirements.
