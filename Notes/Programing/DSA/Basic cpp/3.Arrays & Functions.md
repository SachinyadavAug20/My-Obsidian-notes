## 1. Array Fundamentals

An array is a collection of elements of the same data type stored in contiguous memory locations.

- **Declaration:** `int a[10];` allocates space for 10 integers.
    
- **Indexing:** Zero-indexed ($0$ to $n-1$). For a size of 10, valid indices are `0` through `9`.
    

> [!danger] Segmentation Fault (Out of Bounds)
> 
> Attempting to access `a[10]` on an array of size 10 triggers **undefined behavior** or a **Segmentation Fault**. The compiler does not check this boundaries constraint automatically during compile time.

- **Strings as Arrays:** A `string` in C++ essentially behaves as an array of characters.

> [!Takeaway]
> Arrays decay into pointers when indexed. Because arr[i] resolves to *(arr + i), writing i[arr] resolves to *(i + arr), which points to the exact same address space.
> 

## 2. Multi-Dimensional Arrays (Matrices)

To represent a $3 \times 4$ matrix (3 rows, 4 columns), declare it as:

```cpp
int a[3][4];
```

### Memory & Structural Architecture:

- `a[3][4]` creates a collection of **3 elements** (rows), where each element is itself an array of **4 integers** (columns).
    

```cpp
grid
  | a[0][0] | a[0][1] | a[0][2] | a[0][3] |
  | a[1][0] | a[1][1] | a[1][2] | a[1][3] |
  | a[2][0] | a[2][1] | a[2][2] | a[2][3] |
```

## 3. Competitive Programming Memory Limits (Local vs. Global)

When declaring massive arrays inside functions (locally), you hit the strict constraints of the program's **Stack Memory**.

|**Allocation Scope**|**Maximum Array Size Limit**|**Behavioral Outcome if Exceeded**|
|---|---|---|
|**Locally** (Inside `int main()`)|$\approx 10^5$ elements|**Segmentation Fault** (Stack Overflow)|
|**Globally** (Outside `int main()`)|$\approx 10^7$ elements|**Safe & Allowed** (Allocated in Data Segment)|

```cpp
#include <bits/stdc++.h>
using namespace std;

// Globally declared arrays can go up to ~10^7 size safely
int global_arr[10000000]; 

int main() {
    // Locally declared arrays will crash if they exceed ~10^5 size
    int local_arr[100000]; 
    return 0;
}
```

## 4. Functions & Control Flow

Functions isolate reusable pieces of logic to perform specific tasks.

### Structure of a Function:

```cpp
return_type function_name(parameters) {
    // Code logic
}
```

### The Special Status of `int main()`

- In modern C++ compilers, `int main()` is treated uniquely.
    
- The `return 0;` line tells the operating system that the execution completed successfully.
    
- **Modern Compiler Optimization:** Writing `return 0;` is technically optional in modern environments; the compiler will implicitly insert it if missing.

## 5. C++ References vs. Pass-by-Value

By default, standard primitive variables and objects are **passed by value** (a copy is created). Modifications inside the function do not alter the original variable because it only receives its address value, not its operational binding.

### Pass by Reference (`&`)

To alter the original data directly without allocating pointer variables, append the reference symbol (`&`) to the parameter variable.

```cpp
#include <bits/stdc++.h>
using namespace std;

void increment(int &n) { // Received by reference
    n++; 
}

void modifyString(string &s) { // Changes the actual value of s
    s = "changed";
}

int main() {
    int x = 5;
    increment(x); // x becomes 6
    
    string mystr = "original";
    modifyString(mystr); // mystr becomes "changed"
}
```

## 6. Passing Arrays to Functions

Unlike primitive variables, **arrays are always passed by reference by default**. C++ never creates a duplicate duplicate copy of an entire array when passing it to a function block.

### 1D Arrays

When passing a 1D array, you can omit the primary array size inside the parameter bracket declaration:

```cpp
void printArray(int a[]) { // Brackets left empty
    // Logic
}

int main() {
    int arr[50];
    printArray(arr); // Called by passing just the array name
}
```

### 2D Arrays

When passing multi-dimensional arrays, **you must explicitly provide the size of the second dimension (and any subsequent dimensions)**. Omitting it triggers a compilation error because the compiler needs the column size to calculate memory offsets.

```cpp
// Explicitly stating column size (20) is mandatory
void processMatrix(int a[][20]) { 
    // Logic
}

int main() {
    int matrix[10][20];
    processMatrix(matrix); // Valid function call
}
```

## 7. Competitive Programming Workflow Tip

> [!tip] CP Array Workflow
> 
> Due to the complexity of passing multi-dimensional arrays around functions and the strict local memory storage caps ($\approx 10^5$), the standard workflow in Competitive Programming is to **declare your arrays globally**.
> 
> Declaring arrays globally makes them automatically viewable and editable **everywhere** across all your custom tracking functions without passing parameters. Note that while this is a highly effective optimization strategy for CP speed, it is considered bad practice in real-world production system development.

### Useful Standard Library Functions (`<algorithm>`)

C++ provides optimized built-in utility functions natively:

- `std::swap(a, b)`: Exchanges the values of two variables.
    
- `std::max(a, b)` / `std::min(a, b)`: Evaluates upper or lower comparative boundaries.
