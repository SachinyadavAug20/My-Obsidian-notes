## Abstracted
![[Pasted image 20261106192747.png]]
abstracted index => think like have sorted list.
this is called clustered Index(data is stored in the index) => faster reads.
can also put only the address of the data at the index.
![[Pasted image 20261106195549.png]]
advantages => less data duplication(for more indexed table).
if want to optimize for 2 fields will need to have 2 indexes.
if 2 index double it 2 tables for it => if use address avoided duplication of data.
Middle ground => can have some field as address and some fields as data.
