## Spring AI
make a app summaries customer query in 2 line.
will use chat client for it in spring boot 
service layer
```java
package sachin.yadav.FDE;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.stereotype.Service;

@Service
public class SummarizeService {

	private final ChatClient chatClient;

	public SummarizeService(ChatClient.Builder chatClientBuilder) {
		this.chatClient = chatClientBuilder.build();
	}

	public String summarize(String text) {
		return chatClient.prompt()
			.system("Summarize the user's text in a few concise sentences.")
			.user(text)
			.call() // call API for it
			.content(); // give content of response
	}
}
```
build it using builder design pattern.
write things as ROLE -> user, system.
now in controller make our own API for it.
```java
@RestController
@RequestMapping("/api")
public class SummarizeController {
    private final SummarizeService summarizeService;
    public SummarizeController(SummarizeService summarizeService) {
        this.summarizeService = summarizeService;
    }

    @PostMapping("/summarize")
    public String summarize(@RequestBody String request) {
        if (request == null) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "Field 'text' is required");
        }
        return summarizeService.summarize(request);
    }
}
```
for properties
```properties
spring.application.name=FDE

# OpenRouter exposes an OpenAI-compatible API.
spring.ai.openai.base-url=https://openrouter.ai/api/v1
# export OPENROUTER_API_KEY=sk-or-... before making real calls.
spring.ai.openai.api-key=${OPENROUTER_API_KEY:sk-placeholder}
spring.ai.openai.chat.options.model=openrouter/free

# Surface the upstream OpenRouter error message in HTTP error responses.
server.error.include-message=always
```
