```java
    public void getUserById() {
        try {
            Connection connection = DriverManager.getConnection(url, username, password);
            Statement statement = connection.createStatement();
            String sql = "SELECT id,name,email,age FROM student WHERE id = 2";
            ResultSet result = statement.executeQuery(sql);
            result.next(); // at 1st row
            Student s= mapRow(result);
            connection.close();
            System.out.println(s);
        } catch (SQLException e) {
            System.out.println("Database connection failed");
            e.printStackTrace();
        }
    }
    Student mapRow(ResultSet result) throws SQLException {
        Student s=new Student();
        s.setId(result.getLong(1));
        s.setName(result.getString("name"));
        s.setEmail(result.getString(3));
        s.setAge(result.getInt(4));
        return s;
    }
```

### Execute method
it returns boolean -> true(result is `resultSet`)/false(data is how many row affected).
![[Pasted image 20260811201236.png]]
```java
    public void completeCRUD(){
        try {
            Connection connection = DriverManager.getConnection(url, username, password);
            Statement statement = connection.createStatement();
            String sql = "SELECT * FROM student WHERE id =2";
            boolean result = statement.execute(sql);
            if(result==true){
                ResultSet resultSet=statement.getResultSet();
                resultSet.next();
                Student s= mapRow(resultSet);
                System.out.println(s);
            }else{
                int rowCount=statement.getUpdateCount();
                System.out.println("Number of rows affected "+rowCount);
            }
        } catch (SQLException e) {
            System.out.println("Database connection failed");
            e.printStackTrace();
        }
    }
```
