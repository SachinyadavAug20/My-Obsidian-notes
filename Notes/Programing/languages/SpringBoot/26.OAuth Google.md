## OAuth2
This is like giving consent ![[Pasted image 20260916100423.png]]

- Resource owner -> like user who owns his google calendar.
- Client(who request for resource) -> Spring boot application.
- Authorization server -> example google auth system
- Resource server -> where resource is present(example google calendar API).

#### Authorization flow 
when we allow the google login => google gives us client Id and client secret.
this 2 allow use to use authorities instead of a hacker
1. Authorization request ![[Pasted image 20260916121319.png]] response type say don't directly give token from `frontend` make `backend` API call then, give the token. random string used to identify which redirection callback it way.
2. google handles authentication flow.![[Pasted image 20260916121519.png]]
3. Authorization/consent form for user to allow
4. Authorization code => redirect back to `request_url`, and will give random string called `auth_code` and `state`(our random string).![[Pasted image 20260916121655.png]]
![[Pasted image 20260916121810.png]] `auth_code` is not token it will be used to get the token.
5. exchange code to tokens.![[Pasted image 20260916122000.png]]got this token from `backend` thus, safe and trust able.
   `frontend` code has no meaning.
   hacker can use this code also => solved by `PKCE` 
#### PKCE
PKCE => proof key for code exchange.
before this spring boot generates a `code_verifier` string.
get it's SHA-256 name it `code_challenge` string.
![[Pasted image 20260916122249.png]]
when request authentication request set `code_challenge` with it.
google server remember the this `code_challenge` for this request.(all at `frontend`)
![[Pasted image 20260916122425.png]]
then, does normal login flow. 
at code and token exchange(all at `backend`) : will send `coder_verifier` and google will calculate it's SHA_256 and match it with `code_challenge` and if match then only give token.
due to single direction nature of hashing it makes sure only our application which created the request can get the token.
![[Pasted image 20260916122848.png]]
benefits
- hacker knows `code_challange` can't know `code_verifier` from it.
- thus, achieved security

```java
@Setter
@Getter
@Service
public class UserService {
    private UserRepository userRepository;

    public UserService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }

    public User registerOrUpdate(String provider, OidcUser oidcUser) {
        String providerSubject = oidcUser.getSubject();
        Optional<User> existingUser = userRepository.findByProviderAndProviderSubject(provider, providerSubject);
        if(existingUser.isPresent()){
            User user = existingUser.get(); 
            // update
            user.setName(oidcUser.getClaimAsString("name"));
            user.setEmail(oidcUser.getClaimAsString("email"));
            return user;
        }else{
            User newUser = new User(oidcUser.getClaimAsString("name"), oidcUser.getClaimAsString("email"), provider, providerSubject);
            return userRepository.save(newUser);
        }
    }

    public Optional<User> findByProviderAndSubject(String provider, String subject) {
        return userRepository.findByProviderAndProviderSubject(provider, subject);
    }
}
```

```java
@Service
public class CustomOidcUserService implements OAuth2UserService<OidcUserRequest, OidcUser> {
    private final OidcUserService oidcUserService=new OidcUserService();
    private final UserService userService;
    public CustomOidcUserService(UserService userService) {
        this.userService = userService;
    }
   public @Nullable OidcUser loadUser(OidcUserRequest userRequest) throws OAuth2AuthenticationException{
       // let's spring do real OIDC work
       OidcUser oidcUser = oidcUserService.loadUser(userRequest);
       String provider = userRequest.getClientRegistration().getRegistrationId();
       userService.registerOrUpdate(provider, oidcUser);
       return oidcUser;
   }
}
```
all the work is done by spring internally all redirects and storing and managing tokens(verify code and challenge).
make security config
```java
@Configuration
public class SecurityConfig {
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http, CustomOidcUserService customOidcUserService)
            throws Exception {
        http.authorizeHttpRequests(
                auth -> auth.requestMatchers("/").permitAll().anyRequest().authenticated()).oauth2Login(
                        oauth2 -> oauth2.userInfoEndpoint(userInfo -> userInfo.oidcUserService(customOidcUserService))
                                .defaultSuccessUrl("/profile", true));
    }
}
```
now make a controller
```java
@RestController
public class UserController {
    private UserService userService;

    public UserController(UserService userService) {
        this.userService = userService;
    }

    @GetMapping("/")
    public String home() {
        return """
            Public home

            Login using : localhost:8080/oauth2/authorization/google
            """;
    }

    @GetMapping("/profile")
    public Map<String, Object> profile(@AuthenticationPrincipal OidcUser oidcUser) {
        User user=userService.findByProviderAndSubject("google", oidcUser.getSubject()).orElseThrow();
        Map<String,Object> response=new HashMap<>();
        response.put("internalUserId",user.getId());
        response.put("provider",user.getProvider());
        response.put("subject", user.getProviderSubject());
        response.put("name", oidcUser.getClaimAsString("name"));
        response.put("email", oidcUser.getClaimAsString("email"));
        return response;
    }
}
```
