### Servlet
it is a first java package made to handle HTTP -> in 1997
Servlet containers(it decides which Servlet to call) is called a server 
there are many types of servers 
- Tom cat(most used)
- jetty
- under tone
### Tom cat 
it is a Servlet container in which Servlet runs
it handle all boiler plate of request and response(multi-threading internally)
- open port
- read incoming bytes
- pass HTTP request
- manage threads
- create HTTP response
Servlet response as HTTP-Servlet response and request
```mermaid
sequenceDiagram
    autonumber
    participant Client as Browser / Client
    participant Tomcat as Tomcat Container
    participant Servlet as Java Servlet

    Client->>Tomcat: 1. HTTP Request (GET/POST)
    Note over Tomcat: 2. Parse HTTP data<br/>Create HttpServletRequest<br/>Create HttpServletResponse
    Tomcat->>Servlet: 3. Pass Request & Response objects
    Note over Servlet: 4. Execute service()<br/>Process logic (e.g., DB call)
    Servlet->>Tomcat: 5. Write data into HttpServletResponse
    Tomcat->>Client: 6. Convert to raw HTTP Response
```
this solved website problem for java
