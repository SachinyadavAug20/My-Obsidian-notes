## Custom annotation
make a annotation called `@EvaluateTime`.![[Pasted image 20260809104037.png]]
```java
package sachin.yadav.AOP.annotation;

public @interface TrackExecutionTime{
}
```
it is kind of marker annotation, use it as
```java
    @TrackExecutionTime
    public Student createStudent(Student student){
        return student;
    }

// aspect
    @Component
@Aspect
public class SimpleAspect {
    @Around("@annotation(sachin.yadav.AOP.annotation.TrackExecutionTime)")
    public Student trackExecutionTime(ProceedingJoinPoint proceedingJoinPoint) throws Throwable {
        long start = System.currentTimeMillis();
        try {
            Student student = (Student) proceedingJoinPoint.proceed();
            return student;
        } catch (Exception e) {
            System.out.println("Exception occured " + e.getClass().getName());
            throw e;
        }finally{
            long end = System.currentTimeMillis();
            System.out.println("Execution time for " + proceedingJoinPoint.getSignature().getName() + " is " + (end - start)+" ms");
        }
    }
}
```
now can add this infra logic to any method -> by using annotation.
similar can make other things -> `@Autheticate`,`@Logging`...
#### annotation
need to give following  
1. Where the annotation can be applied. -> meta annotation `@Target`, if not specified then, can use that annotation anywhere.
2. How long the annotation will be available. -> retentation policy can be SOURCE(only in source code not in complied or runtime), CLASS(in code and bytecode not at runtime),RUNTIME(default and in all stages)
```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface TrackExecutionTime{
}
```
there is shorter way to pass annotation without giving full path
```java
    @Around("@annotation(sachin.yadav.AOP.annotation.TrackExecutionTime)")
    
// binding form way
    @Around("@annotation(trackExecutionTime)")
    public Student trackExecutionTime(ProceedingJoinPoint proceedingJoinPoint, TrackExecutionTime trackExecutionTime)
```
It is a marker annotation.
#### Configured annotation
configure it to make log for log time consuming process.
```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface TrackExecutionTime{
    long warnAfter() default 2000;
    String operation() default "unknown";
}
```
can give value to it, also optional as default is provided.
```java
    @TrackExecutionTime(warnAfter = 1500, operation = "create student")
    public Student createStudent(Student student){
        return student;
    }
    @TrackExecutionTime(warnAfter = 1000, operation = "get student")
    public Student getStudent(Student s){
        return s;
    }
```
use it as
```java
@Component
@Aspect
public class SimpleAspect {
    @Around("@annotation(trackExecutionTime)")
    public Student trackExecutionTime(ProceedingJoinPoint proceedingJoinPoint, TrackExecutionTime trackExecutionTime)
            throws Throwable {
        long start = System.currentTimeMillis();
        try {
            Student student = (Student) proceedingJoinPoint.proceed();
            return student;
        } catch (Exception e) {
            System.out.println("Exception occured " + e.getClass().getName());
            throw e;
        } finally {
            long duration = System.currentTimeMillis() - start;
            String operation = trackExecutionTime.operation();
            if (duration >= trackExecutionTime.warnAfter()) {
                System.out.println( "This is a very long operation, operation name: " + operation + ", duration: " + duration);
            } else {
                System.out.println("Execution time for " + proceedingJoinPoint.getSignature().getName() + " for " + operation + " is " + duration + " ms");
            }
        }
    }
}
```

```java
public interface BeanPostProcessor {

	/**
	 * Apply this {@code BeanPostProcessor} to the given new bean instance <i>before</i> any bean
	 * initialization callbacks (like InitializingBean's {@code afterPropertiesSet}
	 * or a custom init-method). The bean will already be populated with property values.
	 * The returned bean instance may be a wrapper around the original.
	 * <p>The default implementation returns the given {@code bean} as-is.
	 * @param bean the new bean instance
	 * @param beanName the name of the bean
	 * @return the bean instance to use, either the original or a wrapped one;
	 * if {@code null}, no subsequent BeanPostProcessors will be invoked
	 * @throws org.springframework.beans.BeansException in case of errors
	 * @see org.springframework.beans.factory.InitializingBean#afterPropertiesSet
	 */
	default @Nullable Object postProcessBeforeInitialization(Object bean, String beanName) throws BeansException {
		return bean;
	}

	/**
	 * Apply this {@code BeanPostProcessor} to the given new bean instance <i>after</i> any bean
	 * initialization callbacks (like InitializingBean's {@code afterPropertiesSet}
	 * or a custom init-method). The bean will already be populated with property values.
	 * The returned bean instance may be a wrapper around the original.
	 * <p>In case of a FactoryBean, this callback will be invoked for both the FactoryBean
	 * instance and the objects created by the FactoryBean. The
	 * post-processor can decide whether to apply to either the FactoryBean or created
	 * objects or both through corresponding {@code bean instanceof FactoryBean} checks.
	 * <p>This callback will also be invoked after a short-circuiting triggered by a
	 * {@link InstantiationAwareBeanPostProcessor#postProcessBeforeInstantiation} method,
	 * in contrast to all other {@code BeanPostProcessor} callbacks.
	 * <p>The default implementation returns the given {@code bean} as-is.
	 * @param bean the new bean instance
	 * @param beanName the name of the bean
	 * @return the bean instance to use, either the original or a wrapped one;
	 * if {@code null}, no subsequent BeanPostProcessors will be invoked
	 * @throws org.springframework.beans.BeansException in case of errors
	 * @see org.springframework.beans.factory.InitializingBean#afterPropertiesSet
	 * @see org.springframework.beans.factory.FactoryBean
	 */
	default @Nullable Object postProcessAfterInitialization(Object bean, String beanName) throws BeansException {
		return bean;
	}
}
```
