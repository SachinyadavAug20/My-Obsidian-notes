## Servlets container
It is tomcat.
It is a java server -> java web application host.
It is long running process -> listen to port(8080).
special class which are mapped when request comes is called a servlet.
tomcat will pass incoming request and give it to correct servlet.
![[Pasted image 20260720192418.png]]
tomcat will have mapping.
can give information to tomcat using special annotation.
It is similar to IOC container in spring which manages object, it manages servlet(object).
![[Pasted image 20260720192726.png]]
This is from where spring got idea of IOC.(servlet container becomes base of spring technology)
Internally it make an object for each request of class `HTTPServletRequest`=> will store(like get host name,URL,headers) request info in this object, and it will make a empty object of class `HTTPServletResponse` and store the return value(set content,header,status code...) of the servlet and format it.(servlet doesn't response back it just edits the object it got from servlet container).
This request and response object are given to servlets to handle the request.

#### Life-Cycle servlets 
1. init() -> like post construct
2. service() -> operation like `doGet()`,`doPost()`... 
3. destroy() -> pre destroy
This are callbacks which can be overridden in the class.
by default servlets is lazy initialization.
internally has many if else and standard methods ![[Pasted image 20260722121502.png]]
```java
package sachin.yadav.servlet;

import java.io.IOException;

import jakarta.servlet.annotation.WebServlet;

@WebServlet("/hello")
public class HelloServlet extends HttpServlet{
    public HelloServlet(){
        System.out.println("HelloServlet constructor");
    }
    @Override
    public void init(){
        System.out.println("HelloServlet init");
    }
    @Override
    public void doGet(HttpServletRequest request, HttpServletResponse response) throws IOException{
        response.setStatus(200);
        response.setContentType("application/json");
        response.getWriter().write("{ \"message\":\"Hello\" }");
    }
    @Override
    void destroy(){
        System.out.println("HelloServlet destroy");
    }
}
```
