## Requirements
- We should be able to manage inventory.(Add/Remove items)
- We should have replenish strategies(Threshold, weekly) & should be scale-able.
- We can have multiple inventory store(like DB inventory etc) and can be further extended
- User should be able to see items from all the dark-stores closer to him/her.(5 Km)
- If one dark-stores cannot fulfill order, one order can be split into multiple DS, fulfilled by multiple delivery agents.
our inventory has many things(from needle to TV and everything) in it.
non-functional requirements are understood.
