### two-factor auth
uses 2 factor
- something you know(like password)
- something you have(like your phone which gets OTP)
also have multi-factor auth
###### Downside
- can forget that factor
still trade off
### Password manager
It is a software manages password => creates, store, and suggest password
don't remember password. -> password(primary)
it is a trade-off
- bad to re-use a password => can attack all if 1 compromise
