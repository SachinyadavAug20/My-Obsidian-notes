```java
@Service
public class SummarizeService {

            .system("Summarize the user's text in a few concise sentences.")
            .user(text)
            .call()
            .content();
    }

    public String chat(String message) {
        history.add(new UserMessage(message));
        String response = chatClient.prompt()
            .messages(history)
            .call()
            .content();
        history.add(new AssistantMessage(response));
        return response;
    }
}
```

```java
@Service
public class SummarizeService {

    private final ChatClient chatClient;

    private List<Message> history = new ArrayList<>();
    private final String SYSTEM_PROMPT = """
            You are a customer-support executive for our Food ordering app named Tomato.
            Your job is to identify the customer's main problem and urgency. Answer them related to there query.

            Use professional language. If user has an issue, use words like I understand your frustration, I am really sorry for your trouble etc.

            Do not answer any other question which is not related to Ordering Food query, refund query, order tracking status query or company policy query.
                    """;

    public SummarizeService(ChatClient.Builder chatClientBuilder) {
        this.chatClient = chatClientBuilder.build();
    }

    public String summarize(String text) {
        return chatClient.prompt()
                .system("Summarize the user's text in a few concise sentences.")
                .user(text)
                .call()
                .content();
    }

    public String chat(String message) {
        history.add(new UserMessage(message));
        String response = chatClient.prompt()
                .system(SYSTEM_PROMPT)
                .messages(history)
                .call()
                .content();
        history.add(new AssistantMessage(response));
        return response;
    }
}
```

## Context window
It is data attached(chat history) with a prompt.
context window is limited => for a LLM.
Context window = input token + output token.
It is the maximum amount of information an LLM can process.
LLM will not remember anything.
LLM will not able to remember you, application/tool provides it with all the information with the prompt.
User prompt never changes parameter of model(that is prompt doesn't change LLM, it is already trained).
Context window => temporary data which is send with every prompt.
![[Pasted image 20261002111026.png]]
problem by nevi sending history will fill the context window very quickly.
tokens wasted exponentially as sending full history.
Solved using
- Will send only starting n message => 
	- may lead to loss of recent message and context loss
- will send only ending n message =>
	- LLM will forget all old conversation and context loss
- will send first m + last n message =>
	- not full proof may loss context
- summary of full context window => 
	- compress/summarize all this conversation
	- add conversation summarize cost => will loss context of details(as summary will not be detailed)
	- hallucination happens due to it as LLM try to full the detail from the summary.
- better approach -> RAG, memory.
not required long prompt for accurate output, need relevant context.(as token is limited so need to be smart).
## Context
LLM -> has history called context of the conversation.
the next token predicted depends heavily on the current context and is assisted by the training data.
example 
```bash
Context A : Explain me docker, i am complete fresher ?
Context B : Explain docker, I am senior engineer ?
```
P(next token | context A) != P(next token | context B).
also context has priority -> system prompt has more priority then, user prompt.
in next chat how chat-GPT remembers it -> using tools and search and tool sends it over => uses RAG and memory.

## Hallucination
Define : LLM sound confident, even when they are wrong.
problem is not being wrong, problem is being confidently wrong.
why hallucinate -> as trained to predict next token, as there is nothing like verify information, validate it.
it is not guarantee in the process of prediction that information is relevant or anytime.
if not enough available information for the topic thus, LLM will fill the gap with most probable wrong data.
will do google search then, may get correct answer.
modern will hallucinate less.
as LLM are not made to response "`IDK`".
reason -> it is ability of to reason again through the token(but still possible it may hallucinate)
like ![[Pasted image 20261002123522.png]] -> may predict future or confidently say wrong answer.
reason for Hallucination
- less information on the topic.
- incorrect information in training data.

there is nothing like this course -> it is responding jargon/Hallucination.
Hallucination can't be prevented full(as it is probabilistic model), can use modern tools such as RAG, memory, validations, guard rails.
