Infinite JSON Recursion
- Problem: Bidirectional JPA relationship (Student → Department → students → Student ...) caused Jackson to serialize infinitely, exceeding 500 depth limit.
- Solution: Use Jackson reference annotations to break the cycle:
```java
// In Department.java
@JsonManagedReference
@OneToMany(mappedBy = "department")
private List<Student> students = new ArrayList<>();

// In Student.java
@JsonBackReference
@ManyToOne
@JoinColumn(name = "department_id")
private Department department;
```

```java
public class Student2{
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String name;
    @ManyToMany
    @JoinTable(
        name = "student_course", 
        joinColumns = @JoinColumn(name = "student_id"), // owning side
        inverseJoinColumns = @JoinColumn(name = "course_id") // inverse side
    )
    private List<Course> courses = new ArrayList<>();
}
```
