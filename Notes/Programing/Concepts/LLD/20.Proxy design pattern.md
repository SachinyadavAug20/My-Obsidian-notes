There is resource and user.
![[Pasted image 20261019164441.png]]
need to avoid user to directly interact with the resource for security.
so, need a proxy between this 2 parties.
![[Pasted image 20261019165002.png]]
Reasons for proxy
- Resource is critical data => proxy will validate user(authenticate and authorize users).
- A check request before giving to resource.
- Resource is not directly connect => connected via interned so, have proxy to connect internet to access that resource => ![[Pasted image 20261019165452.png]], client doesn't know if needed network
Proxy behave like resource.

will have same concept of proxy, proxy will be representation of the resource for a client.
