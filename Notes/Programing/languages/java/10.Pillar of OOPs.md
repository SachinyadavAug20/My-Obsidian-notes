## Encapsulation
###### real word object have encapsulation as a property
###### Encapsulation: to form capsule of data and behavior
- Both data & behavior should be together within an object
- we should not provide unrestricted access to our data -> provide restricted getter and setter methods
```java
public class animal {
  int noOfLegs;
  String name;
  void move(){
    System.out.println("I am moving");
  }
  void eat(){
    System.out.println("I am eating");
  }
}
```
#### Access modifier -> tell how has access to 
- variable
- method
- constructor
- class
###### there are 4 Access modifier 
- public (any one in codebase can access)
- private  (can't access outside current class. only class method can access it.)
- default ((it is by default modifier)anyone can access belonging to same package(it is a group of similar classes/interface together))
- protected (in same package + inherited class)

## Inheritance
###### `is-a` relation like vehicle -> car, student -> engineering student
###### class inherit properties and behavior from parent class
```java
public class demo {
  public static void main(String[] args) {
    car c1=new car("bmw",4,5,2);
    c1.start();   // starting
    c1.display(); // name:bmw| no_of_wheels:4| no_of_gears:5| no_of_doors:2| speed:0
  }
}


class vehical{
  String clor;
  int no_of_wheels;
  int no_of_gears;
  int no_of_doors;
  int speed;
  void speed(int s){
    this.speed=s;
  }
  vehical(int nw,int ng,int nd){
    no_of_wheels=nw;
    no_of_gears=ng;
    no_of_doors=nd;
  }
  void display(){
    System.out.println("clor:"+clor+"| no_of_wheels:"+no_of_wheels+"| no_of_gears:"+no_of_gears+"| no_of_doors:"+no_of_doors+"| speed:"+speed););
  }
  void start(){
    system.out.println("starting");
  }
}
class car extends vehical{
  String name;
  car(String n,int nw,int ng,int nd){
    name=n;
    super(nw,ng,nd); // use parent's constructor
  }
  void display(){  // child can overide parent methods
    System.out.println("name:"+name+"| no_of_wheels:"+no_of_wheels+"| no_of_gears:"+no_of_gears+"| no_of_doors:"+no_of_doors+"| speed:"+speed);
  }
}
```
###### Inheritance provides
- code re-usability
- support polymorphic
###### types
- simple (parent -> child)
- multi-level (parent -> child_1 -> child_2 -> child_3)
- hierarchical inheritance (graph)
- multiple inheritance (many parent -> many child) (not supported in java !can extend only 1 class)
- hybrid

###### Why can't extent from 2 class/multiple inheritance in java ?
- due to diamond problem ![[Pasted image 20260522180842.png]] here, if B inherits `show()` from A and C over-write `show()` then, which `show()` should be passed to D ?? -diamond problem   -------> solved by using interfaces
###### some key word
- this :- reference to current object
- super :- reference of parent object
	- super used to access parent class variable/method
	- use parent class constructor in child class constructor
