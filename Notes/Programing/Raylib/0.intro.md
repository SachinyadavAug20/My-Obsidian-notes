## Game loop
it has parts
1. Event handling(on key press etc)
2. update position(change of position game object)
3. drawing object at new positions.
```cpp
#include <raylib.h>

int main(){
  InitWindow(800, 600, "Raylib");// width,height,title
  SetTargetFPS(60); 
  // Game loop (will run 60 times a second)
  while (WindowShouldClose()==false) { // close when esc is pressed or try closing window
    // 1.Event handling

    // 2.updating positions

    // 3.drawing
    BeginDrawing();
    EndDrawing();
  }
  CloseWindow();
  return 0;
}
```

### Player control
take input from player to do movement
```cpp
  while (WindowShouldClose()==false) {
    // 1.Event handling
    if(IsKeyDown(KEY_RIGHT)){
      ballX+=ballSpeed;
    }else if(IsKeyDown(KEY_LEFT)){
      ballX-=ballSpeed;
    }else if(IsKeyDown(KEY_DOWN)){
      ballY+=ballSpeed;
    }else if(IsKeyDown(KEY_UP)){
      ballY-=ballSpeed;
    }
    // 2.updating positions
    // 3.drawing
    BeginDrawing();
    ClearBackground(green);
    DrawCircle(ballX,ballY, 20, WHITE);
    EndDrawing();
  }
```
there also is `keyPressed` and `keyDown` different same as in Unity and Godot.
