## Iterator pattern
have an object need to iterate over it.
example: have `linkedList`, `BinaryTree`, `PlayList` ... => need to traverse over it.
![[Pasted image 20261108124544.png]]
for playlist depends on implementation for it.
There is a way called as Iterators in C++ and Java.
iterators has methods like `hasNext()`,`next()` to traverse in a DS.
### Why need iterator
example for a song and playlist => ![[Pasted image 20261108125746.png]]
to play entire playlist by iterating over list.
`SRP` => separate storing(business logic) and traversing logic.
so, playlist should not know how to traverse in a list of songs.
iterator has methods `.hasNext()` and `.next()`.
Iterator is to not break `SRP`.
for search may need to iterate over it and return the match.
if data structure changes will make different iterator can do it.
