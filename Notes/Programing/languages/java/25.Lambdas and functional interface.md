class Sortbymarks implements Comparator<Student> {
    @Override
    public int compare(Student o1, Student o2) {
        return o1.marks-o2.marks;
    }
}
class SortbyName implements Comparator<Student> {
    @Override
    public int compare(Student o1, Student o2) {
        return o1.name.compareTo(o2.name);
    }
}
class SortbyRoll implements Comparator<Student> {
    @Override
    public int compare(Student o1, Student o2) {
        return o1.rollNo-o2.rollNo;
    }
}

class Student {
    String name;
    int marks;
    int rollNo;
    public Student(String name,int rollNo, int marks) {
        this.name = name;
        this.marks = marks;
        this.rollNo = rollNo;
    }
    @Override
    public String toString() {
        return "{" + name + "," + rollNo + "," + marks+"}";
    }
}

### Functional interface
- It is a interface which has only one abstract method
- any number of default methods and static methods
example : comparable and comparator interface
uses this functional interface to define lambdas -> which started functional programming in java
## Lambdas
it is use to pass logic directly
```java
// general syntax
(parameter)->expression
```
java will interpret as it is a override of one and only method in functional interface

> [!observer]
> It is similar to JavaScript(only change of arrow `->` instead of `=>`)

```java
import java.util.*;

public class demo {
    public static void main(String[] args) {
        Student s1 = new Student("Rohan", 4, 100);
        Student s2 = new Student("Aman", 1, 80);
        Student s3 = new Student("Bhoom", 2, 90);
        List<Student> l = new ArrayList<>(List.of(s1, s2, s3));
        l.add(new Student("Ravi", 3, 50));
        System.out.println(l); // [{Rohan,4,100}, {Aman,1,80}, {Bhoom,2,90}, {Ravi,3,50}]
        Collections.sort(l,(o1,o2)->{
	        // logic
            return o1.marks-o2.marks;
        });
        System.out.println(l); // [{Ravi,3,50}, {Aman,1,80}, {Bhoom,2,90}, {Rohan,4,100}]
        Collections.sort(l,(o1,o2)->o1.name.compareTo(o2.name));
        System.err.println(l); // [{Aman,1,80}, {Bhoom,2,90}, {Ravi,3,50}, {Rohan,4,100}]
    }
}
class Student {
    String name;
    int marks;
    int rollNo;
    public Student(String name,int rollNo, int marks) {
        this.name = name;
        this.marks = marks;
        this.rollNo = rollNo;

    }
}
```
`o1` and `o2` are object of Student is know by the type of element in list.
Way to declare lambda expression
- multiple parameters : (a,b)->a.something-b.something;
- single parameter : x-> x * x;
- no parameter : ()-> `System.out.println("Hello")`
- multi-line : {} and return statement compulsory
```java
(a,b)->{
	int s=a+b;
	return s;
}
```
if logic small lambdas helpful but, if big logic do class object way
how java know type of parameter
- it infer it from current context 
- example: in collection sort it is the type of items in the list
- This is called as Target typing
- It only works where need functional method(as method clear)
