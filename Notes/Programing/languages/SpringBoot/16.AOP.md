## Code Example
```java
public interface StudentService {
    public Student createStudent(Student student);
}

@Component
public class StudentServiceImpl implements StudentService{
    public Student createStudent(Student student){
        // permission
        long start = System.currentTimeMillis();
        // business logic
        long duration = System.currentTimeMillis() - start;
        System.out.println("Duration is "+duration+" ms");
        return student;
    }
}

@RestController
@RequestMapping("/api/students")
public class StudentController{
    public StudentService studentService;
    StudentController(StudentService studentService){
        this.studentService = studentService;
    }
    @PostMapping
    public ResponseEntity<Student> createStudent(@RequestBody Student student){
        return ResponseEntity.ok(studentService.createStudent(student));
    }
}
```
Now make a decorator
```java
@Component
@Primary
public class LoggingDecorator implements StudentService {
    private StudentServiceImpl studentService;
    public LoggingDecorator(StudentServiceImpl studentService){
        this.studentService = studentService;
    }
    @Override
    public Student createStudent(Student student) {
        // permission
        long start = System.currentTimeMillis();
        // business logic
        long duration = System.currentTimeMillis() - start;
        System.out.println("Duration is "+duration+" ms");
        System.out.println("LoggingDecorator.createStudent");

        return studentService.createStudent(student);
    }
}
```
thus now service is simple and short

## AOP
it decorates service or anyother class to get things to do things before and after it.
OOP -> object oriented programming, map entities from real world in programming
AOP -> Aspect oriented programming, entity opertion should be in it's service, if need to handle API response put in controlller.
![[Pasted image 20260805183541.png]]
AOP handles 3 things
- What -> e.g logging
- Where -> in all service class all methods
- When -> method start and method end.
bean handles objects similar, AOP handles infra logic.
