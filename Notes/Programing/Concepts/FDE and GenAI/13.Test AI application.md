## AI Evals
An AI evaluation or eval is a systematic way of measuring whether an AI system behaves the way we want.
It is like test cases.
expected output is behavior:(like mention terms)
![[Pasted image 20261026124405.png]]
there are 3 things to test AI application
- Test input (that is user prompt)
- Expected behavior 
	- what should be mentioned, proper tool calling etc.
- Evaluation mechanism 
	- can't do direct string matching as have non-deterministic behavior.
	- there are many ways to evaluate.
	- create situation and states which can be tested using code.
	- LLM-as-a-judge or human-as-a-judge

we test entire AI application not only the LLM.

```java
@RestController
public class SupportController {

    private final SupportService supportService;

    public SupportController(SupportService supportService) {
        this.supportService = supportService;
    }

    @PostMapping("/chat")
    public AgentResponse chat(@RequestParam String message) {
        return supportService.chat(message);
    }
}
```
support service
```java
@Service
public class SupportService {

    private final ChatClient chatClient;
    public SupportService(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }

    public String chat(String question) {
         return chatClient.prompt()
                .user(question)
                .call()
                .content();

        );
    }
}
```
