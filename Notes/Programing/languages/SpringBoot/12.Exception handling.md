problem is many checks for null value
```java
    @GetMapping("{id}")
    public ResponseEntity<ResponseDto> getStudent(@PathVariable Long id) {
        ResponseDto student = studentService.getStudent(id);
        if (student == null) return ResponseEntity.notFound().build();
        return ResponseEntity.ok(student);
    }

    @PutMapping("{id}")
    public ResponseEntity<ResponseDto> updateStudent(@PathVariable Long id,@Valid @RequestBody UpdateDto student) {
        ResponseDto student1 = studentService.updateStudent(id, student);
        if (student1 == null) return ResponseEntity.notFound().build();
        return ResponseEntity.ok(student1);
    }

    @DeleteMapping("{id}")
    public ResponseEntity<ResponseDto> deleteStudent(@PathVariable Long id) {
        ResponseDto student = studentService.deleteStudent(id);
        if (student == null) return ResponseEntity.notFound().build();
        return ResponseEntity.ok(student);
    }
```
this null check are exceptions which are not supposed to be handled by controller. -> SOLID.
> [!important]
> Solution divide flow in 2 parts -> happy flow and exception flow.
