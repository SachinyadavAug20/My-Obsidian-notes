## JWT-token
JWT -> JSON web token.
this is special web-token which contain all information to create an authentication object.
Signed JWT provides integrity and authenticity.(that is it is secure).
![[Pasted image 20260913115217.png]]
store sufficient information to make the authentication object in JWT-token.
no need to pass credentials.
JSON to string token is send.
string converted to JSON using `Base64URL`.
process -> make `Base64URL`(URL friendly string 2 way not hashing) of any object and then can use than URL/string to make that object back. -> only encoding not encrypting.
#### Problems
- server trusting a string. 
- if client changes that string and try to get other people account by using hit and try(as client also know how to convert token -> JSON)![[Pasted image 20260913120205.png]] user can make himself admin. -> change token and trick server.
server should not believe the client and versify it's clams.
now, instead of encoding do hashing(because it is one way).
- will hash the authentication JSON.

- solution use both encode and hashing -> ![[Pasted image 20260914094141.png]] this token given to client -> if client changes encoded part then hash will change and we will detect it(fail verification).
server need to check hash of encoded JSON is same as hash provider then verify else error.

```java
    public JwtDecoder jwtDecoder(
            SecretKey secretKey,
            @Value("jwt.issuer") String issuer) {
        NimbusJwtDecoder decoder = NimbusJwtDecoder
                .withSecretKey(secretKey)
                .macAlgorithm(MacAlgorithm.HS256)
                .build();
        decoder.setJwtValidator(JwtValidators.createDefaultWithIssuer(issuer));
```

make service to generate JWT token
```java
@Service
public class JwtService {
    @Value("${jwt.issuer}")
    private String issuer;
    @Value("${jwt.expiration}")
    private Long expiration;

    private JwtEncoder jwtEncoder;

    public JwtService(JwtEncoder jwtEncoder) {
        this.jwtEncoder = jwtEncoder;
    }

    public String generateToken(Authentication authentication) {
        Instant now = Instant.now();
        List<String> authorities = authentication.getAuthorities().stream().map(GrantedAuthority::getAuthority)
                .toList();
        JwtClaimsSet claims = JwtClaimsSet.builder()
                .issuer(issuer)
                .issuedAt(now)
                .expiresAt(now.plusSeconds(expiration))
                .subject(authentication.getName())
                .claim("authorities", authorities)
                .build();
        // header is default and payload is set -> now decode and sign
        Jwt jwt = jwtEncoder.encode(JwtEncoderParameters.from(claims));
        return jwt.getTokenValue();
    }
}
```

```java
@RestController
@RequestMapping("/auth")
public class AuthController {
    private AuthenticationManager authenticationManager;
    private JwtService jwtService;

    public AuthController(AuthenticationManager authenticationManager,JwtService jwtService) {
        this.authenticationManager = authenticationManager;
        this.jwtService=jwtService;
    }

    @PostMapping("/login")
    public LoginResponseDto login(@RequestBody LoginRequestDto loginRequestDto) {
        Authentication authenticationRequest=UsernamePasswordAuthenticationToken.unauthenticated(loginRequestDto.getUsername(), loginRequestDto.getPassword());
        Authentication authentication = authenticationManager.authenticate(authenticationRequest);
        String token=jwtService.generateToken(authentication);
        return new LoginResponseDto(token);
    }
}
```
