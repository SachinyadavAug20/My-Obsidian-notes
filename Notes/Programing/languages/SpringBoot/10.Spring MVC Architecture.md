## Spring MVC
it is actual/official web framework for spring. can make 
- rest API
- web app(HTML/JSP(java servlet pages))
It's module name is `spring_webmvx`.
it give `@Controller`,`@RestController`,`@PostMapping`...
![[Pasted image 20260723091728.png]]
There are many internal thing happen between client and controller.
there are many servlets and tomcat parse and call the appropriate servlet for it.![[Pasted image 20260723092210.png]]
each servlet does repeated work -> request parameter checking, JSON to java object, response creation(java to JSON).
solution
thus, tomcat will handle only 1 servlet -> Dispatcher servlet(will do all repeated task).
will have controllers which will be handled by Dispatcher servlet.
![[Pasted image 20260723093851.png]]
Dispatcher servlet has 
- `HandlerMapping` -> it is endpoint to controller mapping![[Pasted image 20260723094323.png]]
IOC controller will handle all beans -> controller,service and repository beans.
handler will scan components for making mapping table![[Pasted image 20260723095043.png]]
there are 3 way client can share information with server.
- Body -> any type of content -> which is converted by `Jackson`.
- URL params -> like `/user/{id}` which is resolved by `handlerMappingArgumentResolver`.
- query parameter -> already done by tomcat. it makes key value pairs.

student repository
```java
public class studentRepository {
    private Map<Long,Student> Db;
    public studentRepository() {
        Db=new HashMap<>();
    }
    public Student save(Student student){
        Db.put(student.getId(),student);
        return student;
    }
    public Student findById(Long id){
        return Db.get(id);
    }
    public List<Student> findAll(){
        return new ArrayList<>(Db.values());
    }
}
```
in student service
```java
@Service
public class StudentService {
    private StudentRepositor studentRepository;
    public StudentService(StudentRepository studentRepository){ // constructor injection
        this.studentRepository=studentRepository;
    }
    public Student createStudent(Student student){
        return studentRepository.save(student);
    }
    public Student findStudent(Long id){
        return studentRepository.findById(id);
    }
    public List<Student> findAll(){
        return studentRepository.findAll();
    }
}
```
