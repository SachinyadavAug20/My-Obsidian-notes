## Moving platform
new script `MovingPlatform`
need to make it move between 2 position A,B
```cs
using UnityEngine;

public class MovingPlatform : MonoBehaviour
{
    [SerializeField] private Vector2 _position1;
    [SerializeField] private Vector2 _position2;
    [Range(0f,1f)] // _percentAcross a slider
    [SerializeField] float _percentAcross;

    void Update()
    {
        transform.position = Vector2.Lerp(_position1, _position2,_percentAcross);
    }
}
```
as move from 0 to 1 in range it => move platform from 1 position to other.
it is fully flexible can do y-position change combine x-y changes all works. => very versatile
Add Gizmos => for start and end position so easy to handle and design with.
also have `position1` as current position of player for ease of use.
```cs
    private void OnDrawGizmos() {
        Gizmos.color = Color.red;
        var collider=GetComponent<BoxCollider2D>();
        Gizmos.DrawWireCube(_position1, collider.bounds.size);
        Gizmos.DrawWireCube(_position2, collider.bounds.size);
        // current position 
        var currentPosition = Vector2.Lerp(_position1, _position2,_percentAcross);
        Gizmos.color = Color.yellow;
        Gizmos.DrawWireCube(currentPosition, collider.bounds.size);
    }
```

    [SerializeField] float _speed=0.3f;

    void Update() {
        _percentAcross = Mathf.PingPong(Time.time*_speed, 1f); // 0-1f 
        transform.position = Vector2.Lerp(_position1, _position2,_percentAcross);
    }
