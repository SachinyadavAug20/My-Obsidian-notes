## Column oriented storage
![[Pasted image 20261113204246.png]]
all column are stored adjust(on disk) in a file => text or CSV.
why use column oriented.
Row -> better for when we want all values in a row(e.g web app, all details of a person)
Column -> better for when want all the values from one column(e.g analytics of a field).

#### Other advantages of COS(column oriented storage)![[Pasted image 20261113210017.png]]
can do column compression to save storage space as column have related data thus, repeated data.
as no of rejection is between 1-5.
Bit-wise encoding => no of rejection 1 in row 0001100.

#### Benefits of column compression:
- less data to send over the network to a server.
- can keep more data stored in memory of CPU cache.

### Downside of column oriented storage
- Every column must have the same sort order(as need to make sense in row so, need to maintain a order so take is related in row)
- Each write needs to go to many different places on disk.
