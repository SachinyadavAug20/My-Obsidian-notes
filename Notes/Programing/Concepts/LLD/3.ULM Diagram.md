What is operator overloading in C++, and why operator overloading not allowed in other language(java,python) ??
- In C++, operators are symbols that perform operations on values. like +-*/%
- for complex number different way to add show need to show it
```cpp
class Complex {
private:
    int real;
    int imag;

public:
    Complex(int r, int i) {
        real = r;
        imag = i;
    }

    // Overloading + operator
    Complex operator+(const Complex& other) {
        return Complex(real + other.real, imag + other.imag);
    }

    void display() {
        cout << real << " + " << imag << "i" << endl;
    }
};

int main() {
    Complex c1(3, 4);
    Complex c2(5, 2);
    Complex c3 = c1 + c2;
    c3.display();
    return 0;
}
```
- The same operator symbol can perform different operations depending on the types of its operands.
```cpp
10 + 20          // Integer addition
2.5 + 3.5        // Floating-point addition
c1 + c2          // Complex-number addition

// why
Distance d3 = d1.add(d2); // without operator overloading
Distance d3 = d1 + d2;    // with operator overloading
```
also same can give logic for comparision
```cpp
bool operator>(const Money& other) {
    return amount > other.amount;
}
```
The goal is not to invent random meanings for operators. The goal is to make operations on objects natural and readable.

#### Associations
there are 2 types of associatiom  ![[Pasted image 20260912143516.png]]
all 3 types of object association is collectively called as composition. -> they are programatically same but slight logical difference.
##### Class Association
inheritance -> `IS-A` relationship.
```cpp
class A {
    method1();
}

class B : public A {
    method2();
}

main() {
    B * b = new B();
    b->method1();
    b->method2();
}
```

all composition is `Has-A` relation not `Is-A` relation.
Code wise -> `Has-A` is using a member of it.
done by construction injection.
```cpp
class A {
    method1();
}

class B {
    A * a;
    B() { a = new A(); }
    method2(){
    }
}
```
to run method1 need to use A from B and use it.
```cpp
main() {
    B * b = new B(new A);
    b->method2();
    b->a->method1();
}
```
