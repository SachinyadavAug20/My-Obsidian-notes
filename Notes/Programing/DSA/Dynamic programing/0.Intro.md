## DP
It is way of solving problem, to reduce time complexity.
### Problem
Fibonacci number :
It is a series of number 0 1 1 2 3 5.
next number = sum of previous 2 number.
using recursion will do.
![[Pasted image 20261027222032.png]]
```cpp
int fibo(int n){
    if(n==0 || n==1)
        return n;
    return fibo(n-1)+fibo(n-2);
}

signed main() {
    cout<<fibo(10)<<endl;
    return 0;
}
```
it is recursion tree
![[Pasted image 20261028214450.png]]
as number increases to much so, calculate modulo
at nth level have 2^n calls
time complexity = O(2^n)
will go out of time, optimize using DP.
## DP
Don't calculate same answer again and again.
memorize the result calculated and use it instead of calling many time.
store state [[lecture 4) State machines]] => remember the answer from a state using map.

```cpp
unordered_map<int, int> dp;

int fibo(int n){
    if(n==0 || n==1)
        return n;
    if(dp.find(n)!=dp.end()) return dp[n];
    return dp[n]=fibo(n-1)+fibo(n-2);
}

signed main() {
    int n=30;
    cout<<fibo(n)<<endl;
    return 0;
}
```

or using array => full it with value signifying no value -> example -1.
```cpp
const int N=1e5+10;

int dp[N];
int fibo(int n){
    if(n==0 || n==1)
        return n;
    if(dp[n]!=-1)
        return dp[n];
    return dp[n]=fibo(n-1)+fibo(n-2);
}

signed main() {
    memset(dp,-1,sizeof(dp));
    int n=60;
    cout<<fibo(n)<<endl;
    return 0;
}
```

#### Top down
this approach 
```cpp
const int N=1e5+10;

int dp[N];
int fibo(int n){
    if(n==0 || n==1)
        return n;
    if(dp[n]!=-1) return dp[n];
    return dp[n]=fibo(n-1)+fibo(n-2);
}

signed main() {
    memset(dp,-1,sizeof(dp));
    int n=60;
    cout<<fibo(n)<<endl;
    return 0;
}
```
is called as top-down approach.
for n -> n-1 -> n-2 ... -> 1.
go top to down -> called top-down approach.
#### Bottom up approach
calculate small value first and then, big problem.
```cpp
const int N=1e5+10;

int dp[N];

signed main() {
    memset(dp,-1,sizeof(dp));
    int n=5;
    dp[0]=0;
    dp[1]=1;
    for(int i=2;i<=n;i++){
        dp[i]=dp[i-1]+dp[i-2];
    }
    cout<<dp[n]<<endl;
    return 0;
}
```
mostly prefer top-down approach is easy.
Steps for top-down
- Write brute for recursion for the problem.
- make array of dimension equal to no of possible states(can be 2D array)
- memorize the state answer and use it
this can be used to solve most of the problem.
