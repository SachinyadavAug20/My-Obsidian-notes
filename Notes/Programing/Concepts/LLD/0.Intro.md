## Low level design(LLD)
it is focus on scalability, maintainability(easy to debug and test), reuseablility(notification payment are not application focused it is independent like plug-and-play model -> not tightly-coupled).
like mapping algorithum used in many app -> rider,delivery,food order etc.
## What is NOT LLD ?
HLD -> high level design is 
- tech stack(Java spring boot).
- DB choose(SQL or NOSQL or other).
- Server scalling methods.
- Server Cost optimization.
- no code full focus on arhitecture design -> make system design documents.
## HLD, LLD, DSA
all this are used to make a program
- HLD -> system arhitecture.
- LLD -> actual code structure
- DSA -> tool used by LLD to solve problems in code.
If DSA is the brain of an application, LLD is the skelaton.
