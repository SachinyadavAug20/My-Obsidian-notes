### Filters
Filtering happens before dispatcher servlet ![[Pasted image 20260801093834.png]]
thus, filter don't get request object and not decided the endpoint where request is going to land.
Filters are commonly used for 
- logging request/response
- security check -> authentication header check
- request/response modify.
- encoding (`UTF-8`)
filter can 
- inspect the request
- inspect headers
- inspect cookies
- check authentication information
- add response headers
- modify request or response wrappers
- block the request
- allow the request to continue
- log request details
- measure total request duration
can also see request which will never reach dispatcher servlet. -> like `static/logo.png`,`/error`,`favicon.ico`.

Servlets -> not only for HTTP request -> thus filter don't have `HttpServletRequest` it has only `ServletRequest`.
need to cast object to HTTP request object.
`FilterChain` -> as can make chain of filter  ![[Pasted image 20260801110719.png]]
filter chain use to signal next filter
```java
@Component
public class LoggingFilter implements Filter {
    @Override
    public void doFilter(ServletRequest request,
                         ServletResponse response,
                         FilterChain chain) throws IOException,ServletException {
        System.out.println("Request entered in logging filter");
        chain.doFilter(request, response); // call do filter of next filter or give to dispatcher servlet
    }
}
```
after `chain.dofilter()` -> code will of return path -> that is response.
```java
@Component
public class LoggingFilter implements Filter {
    @Override
    public void doFilter(ServletRequest request,
                         ServletResponse response,
                         FilterChain chain) throws IOException,ServletException {
        System.out.println("Request entered in logging filter");
        chain.doFilter(request, response);
        System.out.println("Request exited in logging filter");
    }
}
```
