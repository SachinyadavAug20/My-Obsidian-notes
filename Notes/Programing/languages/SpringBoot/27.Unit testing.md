```java
@Repository
public interface ProductRespository extends JpaRepository<Product, Long> {
    boolean existsByName(String name);
}

@Service
public class ProductService {
    private ProductRespository productRespository;
    public ProductService(ProductRespository productRespository) {
        this.productRespository = productRespository;
    }

    public Product createProduct(Product product) {
        boolean exists = productRespository.existsByName(product.getName());
        if(exists) throw new IllegalStateException("Product already exists");
        return productRespository.save(product);
    }
    public Product getProduct(Long productId) {
        return productRespository.findById(productId).orElseThrow(() -> new RuntimeException("Product not found"));
    }
}
```

### Unit testing and integrated testing
Unit testing -> test a unit of the application.(one module of the application is checked at a time.)
Integration -> test for a flow of multiple components.

### Mockito
If need to make something mock for testing is called Test Double.
Types of test double
- Dummy object -> will do nothing(dummy) used for dependency injection.(e.g give null)
- Stub -> doing a predefined task like get product by id method of dependency always returns same hard-coded data.
- Fake -> more than stub, will mimic full DB -> use internal DB(Maps,H2 DB(in memory DB)).
- mock -> configurable to behave as dummy, stub, fake.
  ![[Pasted image 20260919094626.png]]
mock is made by Mockito.
```java
@ExtendWith(MockitoExtension.class)
public class ProductServiceTest {
    @Mock
    private ProductRespository productRespository;

    @InjectMocks
    private ProductService productService;

	@Test
    void shouldReturnProductWhenProductExist(){
        // arrange
        Product product = new Product(1L, "Test Product", 1000.0,20);
        when(productRespository.findById(1L)).thenReturn(Optional.of(product));
        // act
        Product actualProduct = productService.getProduct(1L);
        // assert
        assertEquals(1L,actualProduct.getId());
        assertEquals(product, actualProduct);
        verify(productRespository).findById(1L); // verify was it called or not
    }
}
```

```java
@WebMvcTest
public class ProductControllerTest {
    @Autowired
    private MockMvc mockMvc;

    @MockitoBean
    private ProductService productService;

    @Test
    void shouldReturnProductWhenProductExist() throws Exception{
        // arrange
        Product product = new Product(1L, "Test Product", 1000.0, 20);
        when(productService.getProduct(1L)).thenReturn(product);
        // act + assert
        mockMvc.perform(get("/api/product/1").accept(MediaType.APPLICATION_JSON))
                .andExpect(status().isOk())
                .andExpect(content().contentTypeCompatibleWith(MediaType.APPLICATION_JSON))
                .andExpect(jsonPath("$.id").value(product.getId()))
                .andExpect(jsonPath("$.name").value(product.getName()))
                .andExpect(jsonPath("$.price").value(product.getPrice()))
                .andExpect(jsonPath("$.stock").value(product.getStock()));
        verify(productService).getProduct(1L);
    }
}
```
