## Inheritance
It is used to stablish relationship between classes.
In real life everything are related.
Car -> manualCar, ElectricCar.  (IS-A relationship)
![[Pasted image 20260911195125.png]]
inheritance syntax:
```cpp
class ManualCar:public Car{
	// shift gear, currentGear
}
class ElectricCar:public Car{
	// chargeBattery, batteryPercentage
}
```
why access modifer in it?
- we know, protected -> child class can access it.
- 3 ways to inherite ![[Pasted image 20260911200930.png]]
- public -> all public member of class `Car` will remain public in `ManualCar`,all protected member of class `Car` will remain protected in `ManualCar`.(as it is copy)
- private -> all public,protected member of Class `Car` will become private in `ManualCar`.(Stop further inheritance).
- protected -> all public,protected member of class `Car` will become protected in `ManulaCar`
mostly will publically inheritance(only in exceptional case will use other).

## Polymorphism
This is also a property of real world objects -> they show different form.
object morphism -> don't directly take from parent can change/morph itself.
![[Pasted image 20260911202954.png]]
every animal runs -> but in different way.
same behaviour show in different ways by different entities.
Same Human `run()` -> will run in different way based on the situation(some parameter changed).
This 2 senariour ![[Pasted image 20260911203249.png]] make the term polymorphsim![[Pasted image 20260911203355.png]].
Thus, there are 2 types of Polymorphsim.
![[Pasted image 20260911203549.png]]
1. Dynamic polymorphism(method overriding) -> differen animal run in different ways.
2. Static polymorphism(method overloading) -> same animal run in different way based on condition.
#### Example : Dynamic polymorphism
all cars can acclerate but in different ways.
electric and manual car -> different ways to accelerate.
make virtual/abstract function -> only defined not declared.
```cpp
class Car{
	virtual acclerate();
}
```
childer have to define it.

#### Example: Static polymorphism
same class will do different behaviour in different situation -> differen parameters.
There can be many different acceration
- acclerate normal
- accelerate rapid
- accelerate sudden
instead of giving different name(like giving different gears of each condition) make it same name different parameters.
will do it using method overloading.
no of arugment and type must be changed.

```cpp
#include <iostream>
#include <string>

using namespace std;

// Base Car class
class Car {
protected:
    string brand;
    string model;
    bool isEngineOn;
    int currentSpeed;

public:
    Car(string brand, string model) {
        this->brand = brand;
        this->model = model;
        this->isEngineOn = false;
        this->currentSpeed = 0;
    }

    //Common methods for All cars.
    void startEngine() {
        isEngineOn = true;
        cout << brand << " " << model << " : Engine started." << endl;
    }

    void stopEngine() {
        isEngineOn = false;
        currentSpeed = 0;
        cout << brand << " " << model << " : Engine turned off." << endl;
    }

    virtual void accelerate() = 0;  // Abstract method for Dynamic Polymorphism

    virtual void accelerate(int speed) = 0;  //Abstract method for Static Polymorphism

    virtual void brake() = 0;       // Abstract method for Dynamic Polymorphism
    
    virtual ~Car() {}               // Virtual destructor
};

class ManualCar : public Car {
private:
    int currentGear;

public:
    ManualCar(string brand, string model) : Car(brand, model) {
        this->currentGear = 0;
    }

    //Specialized method for Manual Car
    void shiftGear(int gear) {
        currentGear = gear;
        cout << brand << " " << model << " : Shifted to gear " << currentGear << endl;
    }

    // Overriding accelerate - Dynamic Polymorphism
    void accelerate() {
        if (!isEngineOn) {
            cout << brand << " " << model << " : Cannot accelerate! Engine is off." << endl;
            return;
        }
        currentSpeed += 20;
        cout << brand << " " << model << " : Accelerating to " << currentSpeed << " km/h" << endl;
    }

    //overriding and overloading accelerate at the same time.
    void accelerate(int speed) {
        if (!isEngineOn) {
            cout << brand << " " << model << " : Cannot accelerate! Engine is off." << endl;
            return;
        }
        currentSpeed += speed;
        cout << brand << " " << model << " : Accelerating to " << currentSpeed << " km/h" << endl;
    }

    // Overriding brake - Dynamic Polymorphism
    void brake() {
        currentSpeed -= 20;
        if (currentSpeed < 0) currentSpeed = 0;
        cout << brand << " " << model << " : Braking! Speed is now " << currentSpeed << " km/h" << endl;
    }
};

class ElectricCar : public Car {
private:
    int batteryLevel;

public:
    ElectricCar(string brand, string model) : Car(brand, model) {
        this->batteryLevel = 100;
    }

    //specialized method for Electric Car
    void chargeBattery() {
        batteryLevel = 100;
        cout << brand << " " << model << " : Battery fully charged!" << endl;
    }

    // Overriding accelerate - Dynamic Polymorphism
    void accelerate() {
        if (!isEngineOn) {
            cout << brand << " " << model << " : Cannot accelerate! Engine is off." << endl;
            return;
        }
        if (batteryLevel <= 0) {
            cout << brand << " " << model << " : Battery dead! Cannot accelerate." << endl;
            return;
        }
        batteryLevel -= 10;
        currentSpeed += 15;
        cout << brand << " " << model << " : Accelerating to " << currentSpeed << " km/h. Battery at " << batteryLevel << "%." << endl;
    }

    // Overriding accelerate - Dynamic Polymorphism
    void accelerate(int speed) {
        if (!isEngineOn) {
            cout << brand << " " << model << " : Cannot accelerate! Engine is off." << endl;
            return;
        }
        if (batteryLevel <= 0) {
            cout << brand << " " << model << " : Battery dead! Cannot accelerate." << endl;
            return;
        }
        batteryLevel -= 10 + speed;
        currentSpeed += speed;
        cout << brand << " " << model << " : Accelerating to " << currentSpeed << " km/h. Battery at " << batteryLevel << "%." << endl;
    }

    // Overriding brake - Dynamic Polymorphism
    void brake() {
        currentSpeed -= 15;
        if (currentSpeed < 0) currentSpeed = 0;
        cout << brand << " " << model << " : Regenerative braking! Speed is now " << currentSpeed << " km/h. Battery at " << batteryLevel << "%." << endl;
    }
};

    myElectricCar->startEngine();
    myElectricCar->accelerate();
    myElectricCar->accelerate();
    myElectricCar->brake();
    myElectricCar->stopEngine();

    // Cleanup

    return 0;
}
```
