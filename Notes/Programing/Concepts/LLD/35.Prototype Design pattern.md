## Prototype design problem
if have object created by a class.
![[Pasted image 20261124111451.png]]
will get object in heap.
to create more and more object need to do same thing repeatedly.
![[Pasted image 20261124113054.png]]
problem
1. Creation of object is expensive operation.
2. if need to create many objects for it.
example: `NPC`(non-player-character) loading on game.
generating `NPC` is expensive => need to create 100 of such object.
solved using prototype design pattern => create copy of original object instead of creating new.
that is cloning the object is cheap operation.
