## Histroy of programming
why need of OPPs, what was wrong is structural programming ?
- Machine language (1/0) -> direct interact with CPU.  => prone to error, tedious, no scalable
- Assembly level language -> use english keywords, converted to machine code by assembler. => tightly-coupled with hardware, prone to error, no scalable, a bit tedious.
- Procedural programming -> before OPPs. has function,loops,blocks,conditionals etc. like recipe set of instruction -> e.g C => complex problem can't be solved
- OOP -> 
	- real world modelling 
		- to solve real word problem need to model the real world. objects interacts.
		- object has -> characteristics(variable or indentifiers) and behavior(methods)
		- example
			- Car  
				- characteristics engine,brand,model,wheels,isEngineOn ...
				- can/behaviour start(),stop(),gearShift(),accelrate()...
			- Ownwer of car
				- characteristic rcNo,car,name...
				- behaviour -> Drive(Car c) ![[Pasted image 20260906213110.png]] as allow owner to have multiple cars(can make any number of object from 1 blue print).
	- Data security.
	- Scalable/reuseable.
Real life object -> need to also map it's action,relations,traits.
thus have 4 pillars of OOPs.
- Abstraction
- Encapsulation
- Inheritance
- Polymorphism
## Abstraction
not need to know all implementation -> hide implementation details only see interface and use it.
like only change gear, acceleration, remote is interface for TV(remote is interface to talk to TV).
In real life objects exist in abstracted form. -> no need to know all data and implementation only need to know it's behaviours.
Define: Hides unnessary details from a client(user of that object), and showcase only what is nessary.
```cpp
#include <iostream>
#include <string>

using namespace std;

class Car {
public:
    virtual void startEngine() = 0;
    virtual void shiftGear(int gear) = 0;
    virtual void accelerate() = 0;
    virtual void brake() = 0;
    virtual void stopEngine() = 0;
    virtual ~Car() {}
};

// Main Method
int main() {}
```
virtual -> like abstract method.
this car is like interface for any car.
need to make actual car which will inherite it. => sports car.
`car` is interface and `sportsCar` is an absolute class.
```cpp
class SportsCar : public Car {
public:
    string brand;
    string model;
    bool isEngineOn;
    int currentSpeed;
    int currentGear;

    SportsCar(string b, string m) {
        this->brand = b;
        this->model = m;
        isEngineOn = false;
        currentSpeed = 0;
        currentGear = 0;
    }

    void startEngine() {
        isEngineOn = true;
        cout << brand << " " << model << " : Engine starts with a roar!" << endl;
    }

    void shiftGear(int gear) {
        if (!isEngineOn) {
            cout << brand << " " << model << " : Engine is off! Cannot Shift Gear." << endl;
            return;
    }
    void accelerate() {
        if (!isEngineOn) {
            cout << brand << " " << model << " : Engine is off! Cannot accelerate." << endl;
            return;
        }
        currentSpeed += 20;
        cout << brand << " " << model << " : Accelerating to " << currentSpeed << " km/h" << endl;
    }

    void brake() {
        currentSpeed -= 20;
        if (currentSpeed < 0) currentSpeed = 0;
        cout << brand << " " << model << " : Braking! Speed is now " << currentSpeed << " km/h" << endl;
    }
    void stopEngine() {
        isEngineOn = false;
        currentGear = 0;
        currentSpeed = 0;
        cout << brand << " " << model << " : Engine turned off." << endl;
    }
}
```

It also say about data security -> data is not directly accessible(access by gurad railed getter and setter).
in Car -> can't access odometer(no of km it runed).
Data security done by Access modifers.
![[Pasted image 20260911184334.png]]
public -> anyone can access it.
private -> nobody outside the class can use it.
protected -> can be used by class or it's children.
```cpp
using namespace std;

class SportsCar {
private:
	// characters
    string brand;
    string model;
    bool isEngineOn;
    int currentSpeed;
    int currentGear;

public:
	// constructor
    SportsCar(string b, string m) {
        this->brand = b;
        this->model = m;
        isEngineOn = false;
        currentSpeed = 0;
        currentGear = 0;
    }

	// behaviour
    void startEngine() {
        isEngineOn = true;
        cout << brand << " " << model << " : Engine starts with a roar!" << endl;
    }

    void shiftGear(int gear) {
        if (!isEngineOn) {
            cout << brand << " " << model << " : Engine is off! Cannot Shift Gear." << endl;
            return;
        }
        currentGear = gear;
        cout << brand << " " << model << " : Shifted to gear " << currentGear << endl;
    }

    void accelerate() {
        if (!isEngineOn) {
            cout << brand << " " << model << " : Engine is off! Cannot accelerate." << endl;
            return;
        }
        currentSpeed += 20;
        cout << brand << " " << model << " : Accelerating to " << currentSpeed << " km
    }
}
// Main Method
int main() {

    SportsCar* mySportsCar = new SportsCar("Ford", "Mustang");

    mySportsCar->startEngine();
    mySportsCar->shiftGear(1);
    mySportsCar->accelerate();
    mySportsCar->shiftGear(2);
    mySportsCar->accelerate();
    mySportsCar->brake();
    mySportsCar->stopEngine();

    // Setting arbitrary value to speed. wrong
    // mySportsCar->currentSpeed = 500; -> error as private data protection

    cout << "Current Speed of My Sports Car is set to " << mySportsCar->currentSpeed << endl;

    delete mySportsCar;

    return 0;
}
```
