### HTTP Status code
divided in families
- `1xx` -> Informational
- `2xx` -> Successful response(200->OK, 201->Created new resource, 204 no content(removed resource))
- `3xx` -> Re-directions(301,302,...)
- `4xx` -> Client side error(400 bad request,404 resource not found,409 conflict(already exist))
- `5xx` -> Server side error(500 internal server error)

@RestController

        this.studentService = studentService;
