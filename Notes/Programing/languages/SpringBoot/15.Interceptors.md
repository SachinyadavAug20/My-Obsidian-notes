Interceptors are spring MVC concept.
In interceptor can 
- Request log
- Authenticate user(Who user is?)
- API response time(Exact CSR(controller service and repository) time)
- Add value to header
- Authorize user(What user is allowed to do?)
- Track which controller method
Interceptor can be used as controller level filter.


## Architecture
![[Pasted image 20260803140407.png]]
when which method of interceptor are called
- `preHandle` -> after handler mapping and before handler adapter, thus it has handler object given by dispatcher servlet
- `postHandle` -> after handler adapter has returned to dispatcher servlet.
- `afterComplete` -> after all view loaded. ![[Pasted image 20260803141333.png]]
if many interceptor -> `postHandle()` and `afterCompletion()` will be called in reverse order of `preHandle()` to maintain the onion peel model.

example
```java
@Component
public class LoggingInterceptor implements HandlerInterceptor {
    private long startTime;
    @Override
    public boolean preHandle(HttpServletRequest request,
            HttpServletResponse response,
            Object handler) throws Exception {
        System.out.println("Incoming request ...");
        System.out.println("HTTP method: " + request.getMethod());
        System.out.println("Endpoint: " + request.getRequestURI());
        System.out.println("Query params: " + request.getQueryString());
        System.out.println("Client IP: " + request.getRemoteAddr());
        System.out.println("Token Header: " + request.getHeader("token"));
        if(handler instanceof HandlerMethod handlerMethod){
            System.out.println("Controller: " + handlerMethod.getBeanType().getName());
            System.out.println("Method: " + handlerMethod.getMethod().getName());
        }
        startTime=System.currentTimeMillis();
        return true;
    }

    @Override
    public void postHandle(HttpServletRequest request,
            HttpServletResponse response,
            Object handler,
            ModelAndView modelAndView) throws Exception {
        System.out.println("postHandle called");
    }

    @Override
    public void afterCompletion(HttpServletRequest request,
            HttpServletResponse response,
            Object handler,
            Exception ex)
            throws Exception {
           long timeTaken=System.currentTimeMillis()-startTime;
           System.out.println("Response Status Code: " + response.getStatus());
           System.out.println("Time Taken: " + timeTaken + " ms");
    }
}
```

## More interceptor
for authentication handling
```java
@Component
public class AuthenticationInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request,
            HttpServletResponse response,
            Object handler) throws Exception {
        String apiKey=request.getHeader("x-api-key");
        if(apiKey==null || !apiKey.equals("secret123")){
            response.setStatus(401);
            return false;
        }
        System.out.println("AuthenticationInterceptor preHandle called");
        return true;
    }
}
```
register it in -> can add URL patter and decide order of interceptor.
URL patterns
- `/api/` -> exact match
- `/api/**` -> anything and any number of things can come after it
- `/api/*` -> only 1 word at place example `/api/student`,`/api/teacher`etc but `/api/student/create` not included
like make authorization interceptor
```java
@Component
public class AuthenticationInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request,
            HttpServletResponse response,
            Object handler) throws Exception {
        String apiKey=request.getHeader("x-api-key");
        if(apiKey==null || !apiKey.equals("secret123")){
            response.setStatus(403);
            response.setContentType("application/json");
            response.getWriter().write("""
                    {
                        "message":"Forbidden form this action only admine can do it."
                    }
                    """);
            return false;
        }
        System.out.println("AuthenticationInterceptor preHandle called");
        return true;
    }
}
```
401 -> unauthorized -> Authenticate
403 -> forbidden
```java
@Configuration
public class WebConfiguration implements WebMvcConfigurer{
    public LoggingInterceptor loggingInterceptor;
    public AuthenticationInterceptor authenticationInterceptor;
    public AuthorizationInterceptor authorizationInterceptor;
    public WebConfiguration(LoggingInterceptor loggingInterceptor,AuthenticationInterceptor authenticationInterceptor,AuthorizationInterceptor authorizationInterceptor) {
        this.loggingInterceptor = loggingInterceptor;
        this.authenticationInterceptor=authenticationInterceptor;
        this.authorizationInterceptor=authorizationInterceptor;
    }
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(loggingInterceptor).addPathPatterns("/api/**").excludePathPatterns("/auth/*");
        registry.addInterceptor(authenticationInterceptor).excludePathPatterns("/api/auth/login","api/public/**");
        registry.addInterceptor(authorizationInterceptor).addPathPatterns("/api/db/**");
    }
}
```
how to connect/chain interceptor 
- make all interceptor `@Component`.
- make chaining by order
```java
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(loggingInterceptor).addPathPatterns("/api/**").excludePathPatterns("/auth/*").order(1);
        registry.addInterceptor(authenticationInterceptor).excludePathPatterns("/api/auth/login","api/public/**").order(3);
        registry.addInterceptor(authorizationInterceptor).addPathPatterns("/api/db/**").order(2);
    }
```
If not given order then, order will be order of registration.
When to use filter and interceptor ??
- By default use spring security(internally uses filter) to authenticate and authorize.
- interceptor is worst for security because user interacts with servlet and is entertained
- because should not allow un-authenticated use to cross the filter.
Request and response body must not be changed.
so use filter and interceptor for logging.
