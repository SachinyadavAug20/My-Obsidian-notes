Interceptors are spring MVC concept.
In interceptor can 
- Request log
- Authenticate user(Who user is?)
- API response time(Exact CSR(controller service and repository) time)
- Add value to header
- Authorize user(What user is allowed to do?)
- Track which controller method
Interceptor can be used as controller level filter.

it has 3 method to override based on it's life cycle.
- `preHandle` -> will be called before any handler(can be controller(REST API), static resource, views) is called.![[Pasted image 20260803101904.png]]onion peel model.
- `postHandle` -> will be called after handler is called 
- `afterCompletion` -> 
```java
@Component
public class LoggingInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request,
            HttpServletResponse response,
            Object handler) throws Exception {
        System.out.println("preHandle called");
        return true;
    }

    @Override
    public void postHandle(HttpServletRequest request,
            HttpServletResponse response,
            Object handler,
            ModelAndView modelAndView) throws Exception {
        System.out.println("postHandle called");
    }

    public void afterCompletion(HttpServletRequest request,
            HttpServletResponse response,
            Object handler,
            Exception ex)
            throws Exception {
        System.out.println("afterCompletion called");
    }
}
```

    public LoggingInterceptor loggingInterceptor;

        this.loggingInterceptor = loggingInterceptor;

        registry.addInterceptor(loggingInterceptor);
    }
}

- `preHandle` -> like code before `chain.toFilter()`
- `postHandle` -> like code after `chain.toFilter()`.
for controller `handler` -> `HandlerMethod` for controller.
```java
    @Override
    public boolean preHandle(HttpServletRequest request,
            HttpServletResponse response,
            Object handler) throws Exception {
        HandlerMethod method = (HandlerMethod) handler;
        String controller = method.getBeanType().getName();
        String methodName = method.getMethod().getName();
        System.out.println("preHandle called");
        System.out.println("Controller Name:" + controller + "\nMethod Name:" + methodName);
        return true;
    }
```
![[Pasted image 20260803132517.png]]
do it safely by using instance of 
```java
    @Override
    public boolean preHandle(HttpServletRequest request,
            HttpServletResponse response,
            Object handler) throws Exception {
        if(handler instanceof HandlerMethod method) {
            String controller = method.getBeanType().getName();
            String methodName = method.getMethod().getName();
            System.out.println("Controller Name:" + controller + "\nMethod Name:" + methodName);
        }
        System.out.println("preHandle called");
        return true;
    }
```
return boolean -> to know weather to proceed
- true : go to next interceptor or controller
- false : stop request right here.
### `postHandle`
it has similar to `preHandle`
```java
    @Override
    public void postHandle(HttpServletRequest request,
            HttpServletResponse response,
            Object handler,
            ModelAndView modelAndView) throws Exception {
        System.out.println("postHandle called");
    }
```
model view -> is a full html page as response.
it has model/view related information. -> in Rest API it will return null.
### `afterComplete`
for Rest API `afterCompletion` is more used.
It is like code after calling `chain.doFilter()`.
```java
    @Override
    public void afterCompletion(HttpServletRequest request,
            HttpServletResponse response,
            Object handler,
            Exception ex)
            throws Exception {
        System.out.println("afterCompletion called");
    }
```
to print response ,stop timer ,get exception ,send error response.
```java
    @Override
    public void afterCompletion(HttpServletRequest request,
            HttpServletResponse response,
            Object handler,
            Exception ex)
            throws Exception {
        if(ex!=null){
            System.out.println("Exception occured:"+ex.getMessage());
        }
        System.out.println("afterCompletion called");
    }
```
if have made global exception handler then, ex will always be null.
view -> rendered complete then calls `afterCompletion`. like it means request is fully processed.
