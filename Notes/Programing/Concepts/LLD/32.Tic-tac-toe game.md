# Tic Tac Toe Game
It's low level design problem.
## Requirements
1. Size of the board should be scale-able(`nXn`)
2. There are standard game rules and should be further extensible(3 in row for `3X3`, `4X4` diagonal not allowed)
3. Allow on app(like toast) notification for Tic-Tac-Toe moves, wins, draws etc.
