## 1. What is Time Complexity?

Time complexity is used to **estimate the execution time** of an algorithm before writing the code. It helps avoid getting a **TLE (Time Limit Exceeded)** error on online platforms.

- **Core Idea:** Instead of measuring time in actual seconds (which varies by machine), we count the **number of statement iterations** as a mathematical function of the input size $N$.
- If the execution of statements is entirely independent of the input size $N$, it is called **Constant Time**, denoted as $O(1)$.

### Linear Approximations

When estimating complexity, we ignore smaller terms and constants because they become irrelevant for very large values of $N$:
- $O(5 + N) \Rightarrow O(N)$
- $O(N + 2) \Rightarrow O(N)$
- If a loop runs $3N$ times, the exact formula is $(3N + 2)$, which simplifies to $O(N)$.
- sequential workflows sum up: $O(N) + O(N) = O(N)$.
- If a loop runs a negligible $K$ times inside or alongside an $N$ loop where $K \ll N$: $O(K \times N) = O(N)$.
## 2. Competitive Programming Constraints
Online judge platforms usually place a time limit of **1 second** on code execution.

|**Number of Iterations**|**Will it pass in 1 second?**|**Notes / Examples**|
|---|---|---|
|**$\le 10^7$**|**Yes** (Happy case)|Standard boundary for most $O(N)$ algorithms.|
|**$> 10^7$**|**No / Risky**|Likely to result in a Time Limit Exceeded (TLE) error.|
|**$10^{13}$**|**Definitely No**|Would take roughly $1000$ seconds ($\sim 15$ minutes) to run.|

> ⚠️ **Rule of Thumb:** If your input size $N$ can reach up to $10^{18}$, **only an $O(\log N)$** solution will ever pass within the time limit ($a = \log_2(10^{18}) \approx 38$ steps).
## 3. Advanced Complexity Analysis

### Quadratic Time $O(N^2)$

When a loop runs inside another loop, the operations multiply:

```cpp
for (int i = 0; i < N; i++) {       // Runs N times
    for (int j = 0; j < N; j++) {   // Runs N times
        // O(1) operations
    }
}
```

- **Exact calculation:** $O(1) + O(N) + N \times O(N) = O(N^2)$.
    
- Any equation like $O(10N^2 + 5N + 1)$ simplifies directly to $O(N^2)$.
    

### Logarithmic Time $O(\log N)$

When the input size is halved at every single step, the runtime drops drastically:

```cpp
while (n > 0) {
    n = n / 2;
}
```

- **Step Breakdown for $N = 8$:** $8 \rightarrow 4 \rightarrow 2 \rightarrow 1 \rightarrow 0$ (Takes **4 steps**).
    
- **Mathematical Derivation:** At the last iteration, $1 = \frac{N}{2^a} \implies 2^a = N \implies a = \log_2 N$.
    
- This is vastly superior to $O(N)$. For $N = 10^5$, an $O(N)$ approach takes $100,000$ operations , while an $O(\log N)$ approach takes just $\approx 15$ operations.
    

### Dependent Nested Loops (Sum of $N$ Natural Numbers)

Consider the following nested loop arrangement:

```cpp
for (int i = 0; i < N; i++) {
    for (int j = 0; j < i; j++) {
        // operations
    }
}
```

- Here, the inner loop depends completely on the value of $i$.
    
- **Total Operations:** $0 + 1 + 2 + 3 + \dots + (N-1)$.
    
- Utilizing the arithmetic progression formula: $\frac{N(N-1)}{2} = \frac{N^2}{2} - \frac{N}{2}$.
    
- Dropping constants and lower terms: $O(\frac{N^2}{2}) \cong O(N^2)$.
    

## 4. Test Case Scenario Analysis

### Scenario A: Large $T$ and small $N$

- **Given:** $T$ (test cases) $\le 10^3$, $N$ (array size) $\le 10^3$.
    
- **Task:** Print the sum of elements in each test case.
    
- **Analysis:** Total operations in worst case = $T \times N = 10^3 \times 10^3 = 10^6$. Since $10^6 < 10^7$, this approach runs safely and will pass.
    
- **Complexity:** $O(T \times N)$.
    

### Scenario B: Sum of $N$ Over Test Cases constraint

- **Given:** $T \le 10^5$, $N \le 10^5$, but with a strict clause: **"Sum of $N$ over all test cases $\le 10^5$"**.
    
- If you design an $O(N)$ per test case logic, the total operations across all iterations will simply be $n_0 + n_1 + n_2 + \dots = \sum N \le 10^5$. This comfortably bypasses TLE markers.
    

## 5. Space Complexity

Space complexity tracks the **amount of memory** an algorithm allocates relative to the input size $N$ in the worst-case scenario.

- **Constant Space $O(1)$:** Allocating standard scalar variables.
    
    ```cpp
    int a = 0;
    int b = 0;
    ```
    
- **Linear Space $O(N)$:** Allocating a single-dimensional data structure.
    
    ```cpp
    int arr[N]; 
    ```
    
- **Quadratic Space $O(N^2)$:** Allocating a matrix/grid structure.
    
    ```cpp
    int matrix[N][N];
    ```
