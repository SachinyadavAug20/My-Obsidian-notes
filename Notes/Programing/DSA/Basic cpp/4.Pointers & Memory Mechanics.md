## 1. Memory Architecture Basics

- **Bits & Bytes:** $\text{8 bits} = \text{1 byte}$. Each bit stores a binary value (`0` or `1`).
    
- **Memory Addresses:** Every single byte of memory has a unique **Hexadecimal Address**.
    
- **Scalar Variables:** If you declare `int x;`, it occupies **4 bytes** of memory. The tracking address assigned to `x` is simply the address of its **very first byte**.
    
- **Contiguous Allocation (Arrays):** Elements inside an array are allocated sequentially right next to each other in memory without gaps.

## 2. Pointer Syntax & Operations

A pointer is a data type variable that explicitly stores the **memory address** of another variable.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int x = 4;
    
    // Declaration: * explicitly indicates variable names 'a' and 'b' are pointers
    int *a, *b; 
    
    // Address-Of Operator (&): Extracts the memory address location of x
    a = &x; 
    
    // Dereference Operator (*): Extracts the "value at" the address stored in a
    cout << *a; // Output: 4
    
    // Modifying values in-place via reference tracking pointers
    *a = 5;     // "Change the value at address 'a' to be 5"
    cout << x;  // Output: 5 (The value of x has been directly changed)
}
```

## 3. Pointer Arithmetic Trap

> [!danger] The CP Math Misconception
> 
> Executing `a = a + 1;` **does NOT add 1 to the address value**.

- **Rule:** When you increment a pointer, its address increases exactly by the **size of the data type** it is pointing to.
    
- **Mathematical Expression:**
$$\text{New Address} = \text{Current Address} + (1 \times \text{sizeof}(\text{data\_type}))$$

```cpp
    A[Byte: 10] -->| + 1 int block | B[Byte: 14]
    B -->| + 1 int block | C[Byte: 18]
    end
```

## 4. Arrays and Pointers Identity

In C++, the raw name of an array acts as a permanent tracking pointer pointing to the exact address of its first element (`index 0`).
$$\text{a} \iff \&\text{a}[0]$$

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a[10]; // Allocates 10 integers contiguously (40 bytes total)
    
    // The statements below are completely identical assignments
    int *ptr1 = a;      
    int *ptr2 = &a[0];  
}
```

## 5. Double Pointers (Multi-Level Indirection)

A double pointer stores the **memory address of another pointer variable**.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int x = 4;
    int *p = &x;     // Single pointer storing address of int variable x
    int **pp = &p;   // Double pointer storing address of int pointer p
}
```

### Addressing Layer Breakdown:

- `*p` $\iff$ `x` (Value of `x`)
    
- `*pp` $\iff$ `&p` (Address of pointer `p`)
    
- `pp` $\iff$ `x` (Value of `x` resolved through both memory hops)
    

```cpp

    pp[Double Pointer: pp] -->|stores address of| p[Single Pointer: p]
    p -->|stores address of| x[Variable: x]
```

## 6. Pass by Pointers

Instead of passing a variable directly by C++ reference syntax (`&`), you can pass a variable's raw memory address into an explicit pointer parameter slot to execute in-place changes.

```cpp
#include <bits/stdc++.h>
using namespace std;

// Receives a raw pointer address parameter
void increment(int *x) { 
    (*x)++; // Parentheses are mandatory because ++ has higher precedence than *
}

int main() {
    int a = 4;
    increment(&a); // Explicitly passing the address using &
    cout << a;     // Output: 5
    return 0;
}
```
