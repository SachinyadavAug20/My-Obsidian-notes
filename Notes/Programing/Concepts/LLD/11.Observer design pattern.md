## observer design pattern
There are many object who wants to know the change of state of a particular object.
so the object will notify all other object(who are listening for it) on it change.

## Polling
when should the observer ask for checking changes in the observable object.
infinity looking for change is waste of resources.
so need to pushing
## Pushing
observable is responsible to tell/notify all observer when it's state changes.
![[Pasted image 20260928192545.png]]
observable will maintain a list of observer and will push them all on change.
