It will be explaining how IOC container handles objects/beans.
- create beans
- manage beans
- destroy bean(GC)
### Singleton beans
life cycle :
1. IOC container starts
2. read configuration file(`AppConfig` is also a bean)
3. call @Bean methods in config and manages object return by it.
4. read bean definition(meta data information) like name it is same as class name but 1st letter small.
5. creation of bean dependency on it's scope => instantiate objects and if constructor injection then will happen with creation
6. dependency injection(other ways)
7. Call all Aware interfaces
8. Initialization step
There is `Aware` interface => give info about bean and container.
example:
```java
@Component
public class UserService implements BeanNameAware{
    @Override
    public void setBeanName(String name) {
        System.out.println("Bean name is "+name);
    }
    public UserService(){
        System.out.println("UserService created");
    }
}

// main
public class App {
    public static void main( String[] args ) {
        ApplicationContext context=new AnnotationConfigApplicationContext(AppConfig.class);
    }
}
```
gives output as
```bash
UserService created 
Bean name is userService
```
this method of aware interface are called by spring. 
this method are called callback method(called by spring).
if it gives bean name then, why called set beans name??
- it is called by spring => it is callback thus spring gives us the settled name for this bean.
- thus, it can't be used to set bean name.
```java
public class App {
    public static void main( String[] args ) {
        ApplicationContext context=new AnnotationConfigApplicationContext(AppConfig.class);
        UserService us=context.getBean(UserService.class);
        us.setBeanName("Menwo"); // not set Bean Name
        us=context.getBean(UserService.class); 
    }
}
```
it will not change the name.
- can't do any changes in bean by calling callback methods.

#### Initialization callbacks
it is more used than aware. => it will use implements a interface and called by spring.
```java
public class CartService {
    Map<Integer,String> map;
    public CartService(){
        map=new HashMap<>();
        System.out.println("CartService created");
    }
    public void addToCart(){
        System.out.println("Added to cart");
    }
}
```
need to do initialization of values or may need to flush the map.
there are some interfaces
1. `InitilizationBean`
2. `init method`
3. `Post construct`(most used)
```java
@Component
public class CartService implements InitializingBean{
    Map<Integer,String> map;
    public CartService(){
        map=new HashMap<>();
        System.out.println("CartService created");
    }
    @Override
    public void afterPropertiesSet() throws Exception {
        System.out.println("Initializing Bean");
        map.put(1, "Hello");
        map.put(2, "World");
    }
    public void addToCart(){
        System.out.println("Added to cart");
    }
    public String getValue(int key){
        return map.get(key);
    }
}

// main



// output
CartService created Initializing 
Bean UserService created 
Bean name is userService 
ApplicationContext :org.springframework.context.annotation.AnnotationConfigApplicationContext@4780ab27, started on Sat Jul 11 16:40:25 IST 2026
```
