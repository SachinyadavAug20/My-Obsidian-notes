## Decorator design pattern
need to enhance the properties/abilities.
will add layer on original object decorate it.
the outer layer can modify the output of the inner one.
![[Pasted image 20260930202450.png]]
enhance it ![[Pasted image 20260930202541.png]]
can stack up this decorator infinity.
![[Pasted image 20260930205045.png]]
thus, dynamically enhance properties of the object using layers of decorators around it.
decorating base object with outer object -> decorator `is-a` object thus, inheritance(buz, need to behave like the base object).
also `has-a` to change the behavior/property dynamically.(that is call the base-object method for same and enhance/change the output thus changing behavior dynamically).
![[Pasted image 20261001194849.png]]
decorator has 2 relation with base class -> `has-a` and `is-a`.
