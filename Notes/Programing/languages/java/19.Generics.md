## Up-casting and Down-casting
```java
public class demo {
    public static void main(String[] args) {
        // up-casting 
        int x=4;
        long y=x;
        System.out.println(y); // 4
        System.out.println(x); // 4

        // down-casting
        long l=12345678;
        int i=(int)l;
        System.out.println(i); // 12345678
    }
}
```

Limitation of using Object as Universal Type
- Type information is lost
- Wrong Object could be inserted
- Casting became necessary when reading
- Many errors shift to runtime
Give type 
```java
public class demo {
    public static void main(String[] args) {
        Box<Integer> b1=new Box<Integer>(10);
        System.out.println(b1.getValue()+20); // 30
        Box<String> b2=new Box<String>("Hello");
        System.out.println(b2.getValue()+" world"); // Hello world
        Box<Boolean> b3=new Box<Boolean>(true);
        System.out.println(b3.getValue()); // true
    }
}

// Generic
class Box<T>{ // type parameter
    private T value;
    Box(T value){
        this.value=value;
    }
    public T getValue(){
        return value;
    }
}
```

#### Restriction on it
Make it take parent of all class which is allowed ==> need `number` 
Integer,Double,Float --> inherit from `Number` class
`Number` class has `.doubleValue()` method will convert to double from any `number`
```java
public class demo {
    public static void main(String[] args) {
        Box<Integer> b1 = new Box<>(10);
        b1.printDouble(); // 10.1
        // Box<String> b2 = new Box<>("Hello"); ERROR : error: type argument String is not within bounds of type-variable T
        // b2.printDouble();
    }
}

// Bounded in Generics
// Upper bound -> T is alteast Number or subtype
class Box<T extends Number>{ 
    T value;
    Box(T value) {
        this.value = value;
    }
    public void printDouble(){
        System.out.println(value.doubleValue()); // error as type unknown. can only access only methods of class Object
    }
}
```
can also restrict by using interface
```java
public class demo {
    public static void main(String[] args) {
        Fish f = new Fish();
        Box<Fish> b1 = new Box<Fish>(f);
        // Box<Dog> b2 = new Box<Dog>(new Dog()); ERROR : cast mismatch
        b1.v.display(); // Displaying Animal
        b1.v.swim();    // Swimming
    }
}

// class can only work with class extending Animal and implementing Swimmable
class Box<T extends Animal & Swimmable>{
    T v;
    Box(T v){
        this.v = v;
    }
}

class Animal{
    void display(){
        System.out.println("Displaying Animal");
    }
}
interface Swimmable{
    void swim();
}
class Dog extends Animal{
}
class Fish extends Animal implements Swimmable{
    @Override
    public void swim(){
        System.out.println("Swimming");
    }
}
```
