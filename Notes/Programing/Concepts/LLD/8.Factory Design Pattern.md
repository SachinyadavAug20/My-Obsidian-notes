## Factory 
It is an analogies to real world factory to create object.
as in strategy design pattern -> has many strategies for algorithms -> make object using composition ![[Pasted image 20260920124334.png]]
this strategies are combined to make a unique object.
creation of object is abstracted.
Robot -> abstracted from object creation, the dependence will be injected at runtime by the creator.
create object using `new` keyword.
in factory design pattern => 
- separate business logic from the object creation logic.
in factory design patter will make a new object named as factory to create new objects![[Pasted image 20260920134011.png]]
client should be de-coupled from the application.
client is not required to know how object is created in our application.
client will give species of the object and factory will create it.

make a burger factor -> to create burger via type(basic, standard, premium).

create burger will have instruction to make burger of the given type(if-else-ladder).
```cpp
#include <iostream>

using namespace std;

class Burger {
public:
    virtual void prepare() = 0;  // Pure virtual function
    virtual ~Burger() {}  // Virtual destructor
};

class BasicBurger : public Burger {
public:
    void prepare() override {
        cout << "Preparing Basic Burger with bun, patty, and ketchup!" << endl;
    }
};

class StandardBurger : public Burger {
public:
    void prepare() override {
        cout << "Preparing Standard Burger with bun, patty, cheese, and lettuce!" << endl;
    }
};

class PremiumBurger : public Burger {
public:
    void prepare() override {
        cout << "Preparing Premium Burger with gourmet bun, premium patty, cheese, lettuce, and secret sauce!" << endl;
    }
};

class BurgerFactory {
public:
    Burger* createBurger(string& type) {
        if (type == "basic") {
            return new BasicBurger();
        } else if (type == "standard") {
            return new StandardBurger();
        } else if (type == "premium") {
            return new PremiumBurger();
        } else {
            cout << "Invalid burger type! " << endl;
            return nullptr;
        }
    }
};

int main() {
    string type = "standard";

    BurgerFactory* myBurgerFactory = new BurgerFactory();

    Burger* burger = myBurgerFactory->createBurger(type);

    burger->prepare();

    return 0;
}
```

```cpp
        }

            return new StandardWheatBurger();
```
