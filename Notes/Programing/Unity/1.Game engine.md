### Branches of unity
- alpha : latest most recent(unstable)
- beta : latest a more stable(not super stable)
- LTS : long term support(2 or 3 year supported)
- Tech stream : it is between LTS and beta => latest stable non-locked version(will use this)
when making project can select which version of unity to use for the project
There are 2D core(deprecated), 3D core(deprecated) => not to choose as non-custom pipeline.
There is 2D URP(universal rendering pipeline) => can render in any devices(good graphics).
Mostly to chose 3D URP and 2D URP![[Pasted image 20260622135549.png]]
go to window -> layout -> choose default 
##### Components
- scene view : game scene
- inspect view : where, there are properties of selected object(like in camera we have background color) => if multiple object selected it will show common properties.
- hierarchy view : it is tree of object which are in game scene
> [!note]
> properties will cascade down in the tree

 - in inspect view there, is lock icon. so, it will not change when select other object
