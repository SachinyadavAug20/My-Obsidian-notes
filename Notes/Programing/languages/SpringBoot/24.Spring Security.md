Terms in security -> Assets, Threat, Trust Boundary.
#### Assets
It is a valuable resource.
example : Data assets, operaational assets, security assets(token), infra assets(db,servers), availablity assets(uptime).
#### Threat
possible harm to this assets is threat.
Vulnerability -> it is a weak point of application which can be used to create threat.
Threat + Vulnerability = attack.
For attacker to create a threat need to find Vulnerability in application.![[Pasted image 20260830100841.png]]
example
1. website allows unlimited password attempts.
2. admin login panel is public without authentication.
#### Trust boundary
when data travels from 1 level to other it crosses trust boundaries.
![[Pasted image 20260830101527.png]]
can't trust internet request as it may be manupliates.
don't trust request which crosses trust boundaries.
client/browser -> can't be trusted.
## Authentication
it has clam -> I am admin.
proof -> usename and password.
will verify proof against clam to accept or reject it.
#### Proofs
There are 3 factors
- Something you know -> password,PIN,personal question(security answer), etc
- Something you own -> Authenticator app, smart card, cryptographic key.
- Something you are -> fingerprint, Iris, face
![[Pasted image 20260830110715.png]]
MFA -> multifactor authentication => It combines more than 1 factor.
