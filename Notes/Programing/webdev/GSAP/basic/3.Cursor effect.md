## Now need to make cursor interact with image
html
```html
    <div id="cursor"></div>
  <main>
    <div id="image"></div>
  </main>
```
css for it
```css
#image{
  background-color: crimson;
  height: 50vh;
  width: 70vw;
  background-image: url(https://images.unsplash.com/photo-1780377328845-0cef39414807?q=80&w=627&auto=format&fit=crop&ixlib=rb-4.1.0&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D);
  background-position: center;
}
```
js
```js
var main = document.querySelector("main");
var cursor = document.querySelector("#cursor");
var image = document.querySelector("#image");

main.addEventListener("mousemove", function (e) {
  gsap.to("#cursor", {
    x:e.x,
    y:e.y,
  })
});

image.addEventListener("mouseenter", function (e) {
  cursor.innerHTML="View More"
  gsap.to("#cursor", {
    background:"linear-gradient(45deg, #f00, #f0f)",
    scale:2,
    ease:"back.out"
  })
});
image.addEventListener("mouseleave", function (e) {
  cursor.innerHTML=""
  gsap.to("#cursor", {
    background:"white",
    scale:1,
    ease:"back.out"
  })
});
```
problem have a glister effect(because mouse div comes above the mouse to it triggers mouse leave) -> thus glitch effect
Solution: add a transparent cover between mouse and div(cursor) --> overlay
```html
  <main>
    <div id="image">
      <div id="overlay"></div>
      <img src="https://images.unsplash.com/photo-1780377328845-0cef39414807?q=80&w=627&auto=format&fit=crop&ixlib=rb-4.1.0&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D" alt="image"/>
    </div>
  </main>
```
```css
#cursor{

  /* position: absolute; as will be only on 1st page*/

}

  background-color: transparent;
  height: 100%;
  width: 100%;
  z-index: 10;
  position: absolute;
}
```
cursor is behind overlay so it won't trigger mouse leave
