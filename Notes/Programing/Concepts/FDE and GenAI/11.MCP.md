## MCP
MCP -> model context protocol.
It is a protocol that is a set of rules => standard protocol to connect AI application to external tool.
Define : MCP is a standard protocol through which AI applications can connect to external tools and data.
![[Pasted image 20261022194819.png]]
have 2 parts
- MCP server
	- where all the tools exist
- MCP client
	- user of server => part of the application which has LLM which needs tools
will have many client and one server.
![[Pasted image 20261022201713.png]]
this interactions between MCP server and client is called as MCP protocol.
Server + LLM = host.
so, three things => host, client and server.
