Expense sharing application in a groups.
Don't allow user to leave group until expense is managed fully.
## Requirements
- User can join/leave a group
- User can add expense in a group
- User can settle an expense in a group
- Adding expense should be based on several strategies(equal split, % split, exact split)
- User can't leave group without settling expenses
- User can also add individuals expenses, outside group(one-on-one)
- A notification to be sent when an expense is add/settled.
Payment is done using a 3rd party application.
