### Object
`OnTriggerEnter2D` is trigger when any other collider enters current objects collider and give the Collider object of that invader.
all polygon collider, box collider, etc are derived from Collider class.
```cs
    AudioSource _audioSource;
    void Awake() {
        _audioSource = GetComponent<AudioSource>();
    }
```
if object don't have such component then will return null, trying to call method on it will cause `NullPointerException`.
like TS we can do safe check
```cs
    void OnTriggerEnter2D(Collider2D collision) {
        _audioSource?.Play(); // splacer for anything
    }
```
"?" it will call only if non-null.

```cs
    private void GroundedCheck()
    {
        Vector2 origin = new Vector2(transform.position.x, transform.position.y - _sr.bounds.extents.y);
        var hitCenter = Physics2D.Raycast(origin, Vector2.down, 0.1f, _layerMask);
        origin = new Vector2(transform.position.x - _floatOffset, transform.position.y - _sr.bounds.extents.y);
        var hitLeft = Physics2D.Raycast(origin, Vector2.down, 0.1f, _layerMask);
        origin = new Vector2(transform.position.x + _floatOffset, transform.position.y - _sr.bounds.extents.y);
        var hitRight = Physics2D.Raycast(origin, Vector2.down, 0.1f, _layerMask);
        isGrounded = hitCenter || hitLeft || hitRight;
        if (isGrounded && _rb.linearVelocity.y <= 0)
        {
            _jumpsAvailable = 2;
        }
    }
    private void movementPlayer()
    {
        GroundedCheck();
        _horizontal = Input.GetAxis("Horizontal") * _horizontalVectocity;
        var vertical = _rb.linearVelocity.y;
        if (Input.GetButtonDown("Fire1") && _jumpsAvailable > 0) {
            _jumpEndTime = Time.time + _jumpTime;
            _jumpsAvailable--;
            _audioSource.pitch = (_jumpsAvailable > 0) ? 1 : 1.2f;
            _audioSource.Play();
        }
        if (Input.GetButton("Fire1") && Time.time < _jumpEndTime)
        {
            vertical = _jumpVelocity;
        }
        _rb.linearVelocity = new Vector2(_horizontal, vertical);
    }
```
if ray-cast on any collider will enable jump(count 2) => if added enemy can jump over them also.
still using old input system.
`GetButtonDown()` -> will be true at frame when pressed the button.
`GetButton()` -> will be true as long as pressed or pressing.
different jump height if click twice(shorter height)
if hold and click again after 0.55(`_jumpTime`) later(higher)
```cs
    private void UpdateSprite()
    {
        _animator.SetBool("isGrounded", isGrounded);
        _animator.SetFloat("horizontalSpeed", System.Math.Abs(_horizontal));
        if (_horizontal < 0)
        {
            _sr.flipX = true;
        }
        else if (_horizontal > 0)
        {
            _sr.flipX = false;
        }
    }
```
it gives value to animator every frame and flips sprite based on moving direction change.
