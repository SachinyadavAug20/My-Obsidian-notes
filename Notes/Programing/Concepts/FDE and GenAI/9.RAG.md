This is called as RAG mode => retrieval(similarity content fetched) augmentation(give only relevant context to the LLM) generation(LLM generates response) => RAG.
#### RAG concept
This is RAG => it uses vector to give LLM only the necessary context instead of giving all of it for a particular query.
basic concept is give only the needed context to answer the query.
in vector DB also when search will use `IVF` or `HNSM` => fast search in the context and give only relevant context.
#### Convert PDF to vector
can't make 1 vector of 1 PDF => as it will lost semantic.
need to be able to cherry pick some part of all PDF which is relevant to our query in hand.
take first 1000 words and make vector.
1 document = many(100) vectors.
![[Pasted image 20261018123944.png]]
will use Vector DB => `Pinecone`.
thus, now LLM has long term memory and RAG will help to retrieve only the relevant context(using vector embedding and comparison) from the history instead of full context.
long term memory as history and vectors in DB.

```java
    private final VectorStore vectorStore;
    private final ChatClient chatClient;

    @Value("classpath*:knowledge/*.pdf")
    private Resource[] policyFiles;

    public ChatbotService(VectorStore vectorStore, ChatClient.Builder chatClientBuilder) {
        this.vectorStore = vectorStore;
        this.chatClient = chatClientBuilder.build();
    }

    @PostConstruct // run on start-up
    public void loadKnowledgeBase() {
        // 1. Read all PDF files.
        // 2. FOr each file I will divide them into chunks
        // 3. I will store those chunks in vector DB --> Pinecone.

        List<Document> allChunks = new ArrayList<>();

        TokenTextSplitter splitter = TokenTextSplitter.builder()
                .withChunkSize(300)
                .build();

        // Loop through each PDF file
        for (Resource resource : policyFiles) {

            PagePdfDocumentReader reader = new PagePdfDocumentReader(resource);
            List<Document> pages = reader.read();
            List<Document> chunks = splitter.apply(pages);
            allChunks.addAll(chunks);
        }
        vectorStore.add(allChunks);
    }
```

```java
    public String answerUserQuery(String question) {
        // 1. Question --> vector
        //2. similrity search in our vector db
        //3. top 4 results fetch

        List<Document> relevantChunks = vectorStore.similaritySearch(
                        SearchRequest.builder()
                                .query(question)
                                .topK(4)
                                .build()
                );// langchain pipeline similifies RAG => it gives context => vector and meta data is store so it retrived

        StringBuilder context = new StringBuilder();

        for (Document document : relevantChunks) {

            context.append(document.getText())
                    .append("\n\n");
        }

        String finalContext = context.toString();

        String prompt = """
                You are an AI customer support assistant for our e-commerce company.

                Answer the customer using ONLY the company information provided below.

                If the answer is not available in the provided information, say:
                "I don't have that information in the company documents."
                
                COMPANMY INFORMATION
                %s
                
                """.formatted(finalContext);

        return chatClient.prompt()
                .system(prompt) // high priority(avoid prompt injection) 
                .user(question) // 
                .call()
                .content();
    }
```
