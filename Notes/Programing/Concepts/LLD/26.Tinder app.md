## Requirements
- user can swipe left/right to a profile
- user can setup him/her own profile
- user can set his/her preferences.
- once there is a match they can chat in chatroom.
- user can see all the profiles near their location.(nearby can be based on different strategies)
- user should get notified when there is a matches, or receive a new message(in chat).
- user matching should be based on several factor and scores(like interest match, location match etc)
 non-functional requirements are understood.
