### Limitation
- lost the performance gain which can be had using multi-thread environment
- Disk is slow(as avoided multi-thread operation thus, not using SSD which does many operation at once, Disk has only 1 head and does one thing at a time).
- Should run everything in memory + hash index, tree index
	- less space
	- data is not durable using WAL(also makes it slow not)
