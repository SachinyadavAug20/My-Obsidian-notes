## Adding context management
Assume some steps are done => ![[Pasted image 20261031133341.png]]
now, store context and history.
in harness, need to know other types of memories.
- Conversation history
	  to-n-fro conversation between client and LLM
- Task state
	  How much work is done till now, like a to-do list
	   ![[Pasted image 20261031140852.png]]
	   ![[Pasted image 20261031140947.png]]
- Model context
  LLM context which is provided to LLM = conversation history + task state.
can compact choose one of conversation history and task state.
give only the information required, because
- Context window fills
- will hallucinate because might have contradictory information
thus, not give everything => give a structured model context to the LLM.
![[Pasted image 20261031142314.png]]
this is called context text compaction.
try not to miss any important detail.
