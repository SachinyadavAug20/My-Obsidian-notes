It is a tool to manage project in java spring boot.
there are many other tools for it.
Apache Maven is very popular and widely used and easy.
## JAR files
traditional flow of java apps
```bash
Demo.java -> compiler -> Demo.class -> any JVM can run
```
- if have many file they will have many .class file to handle which to run when.
- will make a mess
- no standard structure.
to solve this problem has JAR(java archives) => this is package to store .class files, resources, folder etc.
thus, can directly share JAR file.
Library/Dependecies => (has functionality but not runnable)
Application =>  (has library and logic of there use to make it runnable)
Advantages of JAR
- To share java code easily
example can make calculator library `calculator.jar` can be share, with other to be use in there application.
- to use externally libraries => i.e connector for DB(e.g `mysql-connector.jar`)
> [!note]
> If make a library then, jar of dependencies will not be in final jar. has special file which tell which dependencies are need like `Package.json`.
if make a application then, it is a executable JAR thus, will have JAR of all dependencies present in it.
- Java Code + 3rd party libraries(JAR has compiled code) --> compile -> run.
- class path -> to use library .class files
## Maven
it is like package manager.
if need a connector can download it(`mysql-connector.jar`) from net. => un-practical(as version,OS,config miss-match)
- manual effort
- versioning miss-match
- transitive(dependencies of dependencies) dependencies
- if share then, how to make dependencies info need to add manual text file for version and like 
Thus, Maven will download it and keep track of it.
Define : It is a project management Tool. it does
- standard folder structure.
- compile code(by one command `./mvnw spring-boot:run`)
- created JAR file.
- has own life cycle => to compile, create JAR, test and so on.
- Dependencies download(JAR)
can install mavine
no need to have global install of mavine use what comes with project
```java
// instead of 
mvn test
mvn spring-boot:run
// do
./mvnw spring-boot:run
./mvnw clean compile
./mvnw test
```
